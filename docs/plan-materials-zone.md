3. **素材規則**：不計學習進度／小樹苗／成就；不顯示講者姓名、獎銜、職稱；不需要報名審核與費用；「主辦單位」改叫「**建立單位**」；保留「誰能瀏覽」設定；沒有整份素材的時間地點，但**每個項目保留單獨設定日期**；可新增多個「分類區域標題」，點標題可收合；項目若是影片，提供影片時間軸裁切模組（`TimeRangePicker`）；每列開頭圖示依網址類型決定（Google 簡報／文件／試算表、PDF、YouTube 影片＝播放鈕、一般網頁…），三角形播放鈕只留給影片。
4. **短網址分兩層**：
   - **第一層（系列，例 `/Beauty-Starry`）**：仍維持在「設定 › 短網址設定頁」集中管理，只有超級管理員能設（已有 `short_links`）。
   - **第二層（素材，例 `/Beauty-Starry/2027-final`）**：在編輯素材面板最上面加「網址」欄（左邊固定顯示 `learn.hglobal1985.com/系列短網址/`，右邊自己取英文名字，即時檢查重複，旁邊有複製鈕）。**只有超級管理員能設定**。限英數與短橫線、自動小寫、同系列內不可重複、保留字不能用、改名後舊網址永遠有效（比照 `course_url_aliases`）。**只有素材這一層用這個欄位，系列那層不用。**
   - 清單裡單一項目：`/系列/素材/項目編號`，編號系統給，不需取名。
5. **分享網址一律從系列短網址往下長**：系列頁分享 `/Beauty-Starry`（現在錯誤地分享成 `/series/美力之星`）；清單項目分享 `/系列/素材/編號`（現在是 `/course/編號?2`）。沒有設系列短網址就不能分享成短網址（要先設）。
