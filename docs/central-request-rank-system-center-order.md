# 給中央會員 AI 的指令：Amway 三欄順序改為「獎銜 > 系統 > 中心」（業主 2026-11-23 指示，請貼給中央會員那邊的 AI）

業主決定調整 Amway 資料三個欄位的**順序與相依規則**。中央會員是這三個欄位的正本，請中央先改、更新串接指令（`https://id.hglobal1985.com/handoff/learn`）與版本號，所有已串接的 App 再跟進。**行動大學的畫面已先照新規則改好（見下方「行動大學目前做法」），但儲存時仍會被中央舊規則擋下，需要中央這邊修改才完整生效。**

## 新規則
1. **順序**：畫面與欄位定義一律 **獎銜 → 直銷商培訓系統 → 地區教育中心**（`GET /v1/amway/field-definitions` 的欄位順序、中央會員自己的編輯頁、名字旁方框的相關說明都請同步）。
2. **獎銜一律可以選／可以送出，與系統、中心完全無關**。請刪除目前的限制：`PUT /v1/me/amway/fields/rank` 在系統或中心還沒有值時回 422 `invalid_field`（reason `system_center_required`）。
3. **中心只有在「系統 = 寰宇」時才能選**：
   - 系統是寰宇（`education_system` 屬於寰宇系統清單）→ 中心可從清單選擇或勾「無」。
   - 系統不是寰宇（其他系統、「無」、沒填）→ 中心不可選；請接受並視為已填值 `"無"`（App 會自動送 `"無"`），不審核、不顯示方框。
   - 請在後端驗證：非寰宇系統卻送了非「無」的中心，回 422（建議 reason `center_requires_hglobal`），避免各 App 各自判斷不一致。
4. **必填**：勾選「我是 Amway 會員」後三欄仍都必填（系統、中心可用「無」，中心在非寰宇系統時自動為「無」即視為已填）。
5. **審核規則不變**：「寰宇＋同時填了地區教育中心」時，中心與獎銜才需審核（獎銜不再被系統／中心的填寫順序卡住，但審核判斷仍看目前系統與中心的值）。

## 系統選「其他」時：隱藏「中心」欄，原位置改成自訂內容輸入欄（業主 2026-11-23 追加）
- 「直銷商培訓系統」下拉選單選了「其他」（自訂系統）時，**「地區教育中心」欄整個隱藏**，在**同一個位置**顯示「自訂系統」的輸入框（要填寫自訂系統名稱；欄位標籤「自訂系統」，沒填時依「必填」規則顯示必填標籤與橘框）。
- 此時中心依規則 3 視為已填 `"無"`（非寰宇系統），App 自動送出，會員看不到也不能改；改選回「寰宇」或清單中的其他系統時，自訂輸入框消失、中心欄恢復（系統是寰宇才可選）。
- 中央會員自己的編輯頁與串接指令的畫面規範請一併統一；「其他」的自訂內容仍走原本的系統欄位值（`education_system` 直接存自訂文字）。

## 「我是 Amway 會員」勾選列勾選後自動隱藏；勾「無」時下拉欄位寬度不變（業主 2026-11-23 追加）
- **勾選列**：會員勾選「我是 Amway 會員」之後，這一列勾選標題**自動隱藏**，畫面只剩三個欄位；沒勾選時才顯示這一列。（取消 Amway 的入口請中央自行安排，例如放在會員中心設定；各 App 資料頁不再顯示這一列。）
- **欄位寬度**：三個下拉欄位的寬度剛好符合文字；但**勾選旁邊的「無」時，欄位寬度必須維持勾選前的寬度，不可縮成「無」一個字的寬度**，取消勾選也不再變動。

## 「必填」標籤要依目前的選擇動態顯示（業主 2026-11-23 追加）
三個欄位旁的「必填」標籤（與「缺的時候提示請填寫」、必填橘框）**不可固定顯示**，要依會員**當下的選擇結果**決定這一欄現在是不是「必須填、而且還沒填」：
- **獎銜**：勾了「我是 Amway 會員」且獎銜還沒選（也沒勾「無」）→ 顯示「必填」；已選或勾「無」→ 不顯示。
- **系統**：勾了「我是 Amway 會員」且系統還沒選（也沒勾「無」）→ 顯示「必填」；否則不顯示。
- **中心**：**只有系統是寰宇時**才需要填 → 系統是寰宇且中心還沒選（也沒勾「無」）才顯示「必填」；系統不是寰宇（其他系統、「無」）時中心自動為「無」、不顯示「必填」；系統還沒選時中心還不能選，也不顯示「必填」。
- 沒勾「我是 Amway 會員」時三欄都不顯示「必填」。
- 送出時的前端提示與後端驗證用同一套判斷：中心在非寰宇系統時不算缺漏。
- 「審核通過／審核中」等狀態標籤不受影響，照原規則。

## 行動大學目前做法（中央改完前的過渡）
- 畫面順序：獎銜 | 系統 | 中心；系統選「其他」時中心欄換成「自訂系統」輸入框（`apps/mobile/src/features/profile-prompt.tsx`）；獎銜永遠可選；系統選非寰宇時中心自動填「無」並停用，換回寰宇再清空讓會員選。
