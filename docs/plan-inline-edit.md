# 規劃：課程頁原地編輯、小編、中心（業主 2026-11-14 討論紀錄，尚未執行）

業主指示：一次到位全部完成（不分階段）；確認完所有問題才開始。

## 已決定
### 原地編輯
- 有課程教材權限的人（總部：超級管理員、總部秘書；該中心的會長、音控；小編）在課程介紹頁上方工具列多一個「編輯」，進入編輯模式；學員看到的公開佈局完全不變。
- 編輯模式：每個區塊旁出現鉛筆，點了從下方彈出該區欄位，各區分開儲存；頁面上看不到的設定（審核群組、報名資格、誰可瀏覽、限時免費、顯示完整版…）放頁面最下方「進階設定」（只有管理者看得到）。
- 「設定→課程設定」所有欄位與「章節與影片」全部搬到課程頁，重新整理分組：基本資料、圖片、時間地點、費用、報名與資格、章節與影片、上架／複製／刪除。全部完成後刪除「課程設定」頁。
- 新增課程：「全部課程」上方功能列「＋新增」（有權限者才看得到）。
- 草稿：有權限的人在「全部課程」看得到自己能管的未上架課程，標「未上架」。
- 封面同步工具刪除（業主已執行過）。
- 短網址管理移入課程頁原地編輯；**只有超級管理員可以改**。關鍵字、課程排序兩頁不動。
- 確認動作一律用底部確認面板（刪除不再用輸入 YES）。

### 小編
- 音控、會長、總部可指派同中心會員為小編；小編歸屬中心（換音控不受影響）；小編不能再指派小編。
- 三種權限可單獨開關：新增（自己新增的課程有完整權限，含上下架、刪除）、修改別人、刪除別人。「別人」＝同中心、非本人新增的課程（現有課程一律算別人的）。「修改別人」包含上下架、價格、報名資格、審核群組。
- 選人：從中央「同中心會員名單」點選，不可手動貼 ID。需求已交中央（docs/central-request-center-members.md），等中央回覆串接指令。
- 小編每次登入以本人的 eligibility/context 確認中心仍相同，換中心自動失效。小編資料只存在行動大學。
- 所有修改記錄是誰、何時改。

### 刪除與下架封存
- 已有人報名繳費的課程：按鈕叫「**下架封存**」，不是永久刪除；小編也可以下架封存。
- 完全沒有人報名繳費的課程：按鈕叫「**刪除課程**」，真的永久刪除。

### 其他
- 網頁版部署即生效；App 版可能要等下次 App 更新，實機沒驗證的要老實說。

### 中心（系列維持現狀）
- 「中心」＝課程的主辦單位（中央中心清單），不另建資料。
- 全部課程上方「分類」旁加「中心」下拉；每個中心可有短網址（只有超級管理員能設定）；管理權限依主辦中心劃分。
- 每個中心有自己的頁面與 EDM（細節討論中）。

### 下架封存
- 已繳費學員封存後照常上課（學習中、訂單紀錄照常），不出現在全部課程、不能再報名。
- 可還原：總部、會長、音控。
- 「有人報名」＝已開通、免費報名、待審核；已取消的不算。
- 封存的課程：管理者在全部課程選中心時，最下面「已封存」可展開。
- 「下架」（暫時收起）與「下架封存」（結束不再開）是兩個不同按鈕。

### 小編管理入口
- 設定頁「小編管理」（總部、會長、音控才看得到）：列出該中心小編、三個權限開關、新增小編。
