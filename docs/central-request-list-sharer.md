# 請中央協助：清單分享者名片（獎銜、獎章圖）

行動大學新增「加入我的清單」（會員自己建立、公開分享的清單，網址 `/安麗會員編號/網址名稱`）。每份清單最上面要顯示「分享者名片」：頭像、姓名、**獎銜、獎章圖＋動畫**，和行動大學首頁的會員名片一致。

## 目前的限制
- 頭像、姓名是會員中心的公開資料，行動大學已能取得並顯示。
- **獎銜、獎章圖屬 Amway 資料，行動大學不得保存**，所以只能「每次有人打開清單時，才向中央查詢分享者」。
- 現有的 `POST /v1/apps/learn/members/lookup`（服務 Token）目前只用於上手白金／鑽石欄位；不確定是否可查他人的 `rank`（獎銜）與獎章圖，也不確定欄位代碼。

## 需要中央提供（任選一種）
1. 在 `members/lookup` 的可選欄位中，開放 `rank`（獎銜顯示名稱）與 `rank_badge`（獎章圖網址與圖案範圍 width／height／top／bottom，格式同 `GET /v1/amway/field-definitions` 的獎銜徽章資訊），`use: "display"`；或
2. 新增「依會員編號或 member_id 查公開名片」的 API，回傳 `display_name`、`avatar_url`、`rank_label`、`rank_badge`。

## 行動大學這邊的做法
- 只在公開清單頁每次載入時查詢，結果只放記憶體快取（10 分鐘內），**不寫資料庫、不寫日誌**。
- 查不到、403、422、429、逾時一律不顯示獎銜與徽章（只顯示頭像與姓名），不影響清單。
