# 「我的圖書館」規劃（業主 2026-11-17 已選定版面，尚未開工）

## 原始需求（業主 2026-11-17 早上 8:49）
- 讓會員個人單獨擁有自己專屬的個人頁面。
- **不會顯示在行動大學網站的任何地方**（清單、搜尋、推薦都沒有），除非取得他個人頁面的專屬網址。
- 個人頁面要有所區隔，**不要跟行動大學標準頁面一樣**，要有圖書館的風格。
- **只有超級管理員**可以指定哪些會員擁有個人頁面的管理權限。
- 擁有權限的會員從「設定」裡面進入「**我的圖書館**」。
