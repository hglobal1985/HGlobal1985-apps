# 給中央會員 AI 的指令：「自訂系統」出現寰宇旗下中心名稱時要提醒改選寰宇（業主 2026-11-24 指示，請貼給中央會員那邊的 AI）

業主新增一條**會員填寫資料的規則**，請中央會員（Amway 三欄的正本）先實作、更新串接指令（`https://id.hglobal1985.com/handoff/learn`）與版本號，所有已串接的 App 再跟進。**行動大學的畫面已先做好提醒（見最下方），但這條規則的正本在中央。**

## 規則
會員在「直銷商培訓系統」選「其他」、自己輸入**自訂系統**名稱時，如果輸入的文字**包含**下列任何一個詞，就要提醒會員：

> 飛登　　蓁分享　　有賢社　　聚冠

這四個其實是**寰宇系統底下的「中心」**，不是獨立的系統。提醒文字（建議）：

> 「蓁分享」屬於寰宇系統：請把「系統」改選「寰宇」，再從「中心」切換選擇。

（文字中的詞換成實際命中的那一個。）

## 實作建議
1. **畫面（中央會員自己的編輯頁）**：自訂系統輸入框下方即時顯示上面的提醒（紅／橘色小字），命中就一直顯示；不阻擋輸入。
2. **API 驗證（建議）**：`PUT /v1/me/amway/fields/education_system` 收到「其他」自訂值、且文字包含上述任一詞時，回 422，`reason: "use_hglobal_center"`，訊息為上面的提醒文字，**讓各 App 不用各自判斷也能擋下**。若中央決定只提醒、不擋，請在串接指令明寫「只提醒不擋」，行動大學就維持只顯示提醒。
3. **詞清單放在中央一份**（建議放平台設定或 `GET /v1/amway/field-definitions` 的欄位定義回傳，例如 `education_system.hglobal_center_words`），之後業主增減詞時所有 App 不用改程式。**行動大學目前寫死這四個詞**（`profile-prompt.tsx` 的 `HGLOBAL_CENTER_WORDS`），等中央提供清單後改讀中央的。
4. **已存在的資料**：目前系統欄是上述詞的會員（例如系統填「蓁分享」），請中央提供一個一次性方式（或請業主在後台逐筆）改成「系統＝寰宇、中心＝該詞」。**行動大學不會自行改會員資料。**

## 行動大學目前做法
- `features/profile-prompt.tsx`：系統選「其他」的「自訂系統」輸入框下方，命中任一詞就顯示提醒（不阻擋儲存）。
- 規則文件：`docs/rules/member-central.md`。
