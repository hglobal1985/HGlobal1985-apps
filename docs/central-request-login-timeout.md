# 請中央會員系統配合：取消「登入逾時」限制（行動大學 2026-11-21）

杜杜龍要求：**取消登入逾時的設定**。會員在行動大學按「登入」後，跳到會員中心（`id.hglobal1985.com/login…`）若停留較久，會看到：

> 登入沒有完成　登入逾時，請回到 App 再試一次。

會員的體驗很差（例如先去查 Google 帳號、接電話、切換 App 之後再回來，就被判定逾時）。

行動大學這端已完成（不再有自己的 10 分鐘限制，登入暫存跨分頁保存）。**剩下需要中央配合的部分**：

1. **登入流程的有效時間大幅放寬或取消**：`/v1/auth/nonce` 發出的 nonce、`/auth/google/start`、`/auth/sso/check` 帶的 `state`／`nonce` 與登入中間頁（「登入沒有完成」那個畫面）的逾時限制，改成至少 24 小時，能取消最好。請告知目前各個環節的逾時數值（nonce TTL、登入頁 session、Google 授權往返等）。
2. **逾時時不要顯示死胡同**：萬一真的過期，不要只顯示「請回到 App 再試一次」，請提供「重新登入」按鈕，直接重新發起一次登入並回到原本要去的 App（`app_id` 與 `return` 網址沿用）。
3. 安全上仍要維持：nonce／state **一次性、只能用一次**、綁定 `app_id` 與 return 網址；放寬時間不影響這些檢查。

完成或有限制時，請回覆行動大學：目前各環節的逾時數值、改成多久、是否支援「重新登入」按鈕。
