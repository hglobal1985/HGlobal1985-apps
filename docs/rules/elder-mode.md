# 至尊模式／超派模式（使用模式切換）

- **至尊模式＝給長輩的大字簡易版；超派模式＝原本的完整版（業主 2026-11-24，B 方案；課程頁採方案 2；移除「唸給我聽」，因為教材本身都是影音）**。
  - **開關與儲存**：`src/lib/elder-mode.ts`（`useElderOn`／`useElder`／`setElder`）。只存在這支手機／瀏覽器（網頁 localStorage 鍵 `elder-mode:v1`，App 用 AsyncStorage），不上傳伺服器。預設超派模式。
  - **模式鍵**：底部主選單「設定」右邊（`src/ui/bottom-bar.tsx`）。超派模式顯示黃色「👑 至尊」（皇冠是自己畫的 SVG `features/elder/crown-icon.tsx`，不另外下載圖示字型），按下直接切換並回首頁；至尊模式顯示「🛠 超派」，按下打開模式面板 `features/elder/elder-sheet.tsx`。書櫃頁面不顯示模式鍵。
  - **至尊模式的主選單**：首頁、課程、學習中、通知＋「超派」鍵；**不顯示「設定」分頁**。選單變高、字與圖示變大，但用固定大小（`uiOnly`），不跟著至尊字體倍數再放大。
  - **模式面板**（取代設定分頁）：字體大小（大的「－／＋」鍵，範圍 120%～220%、每次 10%，面板上有範例字即時預覽，**面板關閉才套用到全站**）、「跟著手機的字體大小」勾選、訂單紀錄、帳號（進 `/me`，至尊模式下該頁不顯示我的清單、我的書櫃、管理功能）、「換回超派模式」（**一定先跳確認面板**，避免長輩誤按）、完成。
  - **字體放大**：`lib/global-scale.ts` 統一處理：全站文字倍數＝平板／電腦倍數 × 至尊倍數（`elderTextScale()`＝自訂倍數 × 手機系統字體倍數，上限 300%）。改倍數或切換模式時根版面用 `useElderVersion()` 當 key 重建頁面（網址與所在頁面不變）。固定版面（底部選單）的字加 `dataSet={{ uiOnly: "" }}`、圖示加 `uiOnly` 屬性＝只吃平板倍數。
  - **跟著手機的輔助設定**：這是 2026-11-24「系統字體不可影響 App」規則（member-central.md）的**唯一例外，只限至尊模式且勾選時**。App（iOS／Android）讀 `PixelRatio.getFontScale()`；網頁在 iPhone／iPad Safari 用 `-apple-system-body` 量出系統文字大小（標準 17px）；其他瀏覽器量不到就當 100%。仍維持 `allowFontScaling=false`，倍數由我們自己乘，不會被系統再放大一次。超派模式完全不跟系統。螢幕大小（手機／平板）照原本 `useLayout()` 自動調整。
  - **首頁**（`features/elder/elder-search.tsx`，`mode="home"`）：上方大搜尋框，中間一顆大麥克風（按一下用說的，網頁用瀏覽器內建語音辨識 `features/elder/use-voice.ts`，中文台灣；說話時顯示「正在聽…」聲波＋聽到的字＋停止鈕；不支援語音的瀏覽器改成打開鍵盤，請長輩按鍵盤上的麥克風），下方黃色「繼續上課」（最近學過、還沒學完的課）。打字或說完原地列出結果：一列一堂課，大縮圖、大字標題、狀態標籤（已報名／審核中／免費／付費／費用未公布／教材），整列可點。搜尋用與寰宇大學相同的索引（`course-search.ts`，找不到再用容錯比對）。
  - **課程分頁**（`mode="browse"`）：同一個大搜尋框（框內小麥克風）＋全部課程大字清單（上架中、不含只限網址的課程；已報名的排前面、清單卡排最後）。
  - **課程頁**（`features/elder/elder-course.tsx`，由 `app/course/[id].tsx` 在至尊模式時改用）：上方兩個大分頁「上課／介紹」（還不能看時預設「介紹」）。上課＝下一課（正在播放的優先）綠底大列排第一，接著其他還沒上的，已上完的淡色放最後；鎖住時有「報名後才能觀看，按這裡看介紹與報名」。介紹＝EDM 封面、主講、堂數與分鐘、日期、地點、主辦中心、費用、報名按鈕（固定在下方，沿用原本的報名／審核中／取消流程）、已報名時「去上課」。播放中播放器固定在分頁上方。
  - **至尊模式隱藏的進階功能**：加入我的清單（`HeaderAddToList`／`RowAddToList`）、留言板（`CommentBoard`）、學習成就（`SaplingBar`）、我的書櫃與我的清單入口、管理員編輯模式（課程頁 `manages` 一律 false）、所有「＋新增」浮動鈕（`AddMaterialFab`）、設定頁的管理區。新增進階功能時，若不適合長輩，就在元件入口用 `useElderOn()` 擋掉（做法：匯出的元件包一層，至尊模式回傳 null）。
- **模式鍵樣式改版（業主 2026-11-24 第二次）**：拿掉黃色底框，樣式跟其他分頁一樣（白色圖示＋白字，不會變成黃色膠囊）；**文字與圖示顯示「目前的模式」**：超派模式＝「超派」＋`MAKER_ICON`（`bottom-bar.tsx` 常數，業主從五個方案挑；挑選前暫用 `construct-outline` 工具圖示），按下直接切到至尊模式；至尊模式＝「至尊」＋皇冠，按下打開模式面板。
- **讀取逾時保護（業主 2026-11-24 回報至尊模式「學習中」一直轉圈，本機與伺服器紀錄都查不到原因）**：`useApi`（`state/session.tsx`）讀取超過 12 秒還沒有資料，就自動重抓一次，並用 `reportClientError("stuck", …)` 把當時狀態（ready、loading、是否登入、ssoGiveUp、loadedOnce、seq）寫進 Workers 紀錄（訊息開頭 `client error`），下次再發生可以照紀錄追查根本原因。
- **「創客模式」更名為「超派模式」（業主 2026-11-24 第三次）**：畫面、面板、確認文字、文件一律叫「超派模式」（本檔上方舊條目已一併改名）。超派模式的模式鍵圖示＝方案 3 火箭 `rocket-outline`（`MAKER_ICON`），面板「換回超派模式」按鈕也用火箭。
- **模式設定檔＝兩種模式差異的唯一來源（業主 2026-11-24 要求長期維護穩定）**：`src/lib/app-mode.tsx` 的 `MODE_PROFILES` 寫死兩種模式各自的：主選單分頁（`tabs`）、首頁版面（`home`）、課程分頁版面（`courses`）、課程頁版面（`coursePage`）、選單放大（`bigNav`）、字體可調（`fontAdjustable`）、離開前確認（`confirmLeave`）、功能開關（`features`：addToList、comments、achievements、myLists、library、manageSection、adminEdit、addButton）。**畫面不可自己判斷「是不是至尊模式」**，一律用 `useFeature("功能名")`、`useModeProfile()` 或 `<ModeGate feature="…">`。要改某個模式顯示／隱藏什麼，只改 `MODE_PROFILES` 的 true／false；新增功能先在 `FeatureKey` 加名字、兩個模式各填值。模式名稱（至尊／超派）也只寫在這裡（`name`），畫面文字用 `MODE_PROFILES.xxx.name` 組字。`lib/elder-mode.ts` 只負責「目前是哪個模式＋字體倍數」的儲存。
- **說話時的音波（業主 2026-11-24）**：`use-voice.ts` 回傳 `levels`（9 條、0～1），「正在聽…」畫面的音波高度跟著麥克風音量即時跳動（每 50 毫秒更新，網頁加 90 毫秒高度過渡）。真實音量用 `getUserMedia`＋`AnalyserNode` 頻譜（人聲頻段、中間高兩邊低）；**Android 不另開麥克風**（可能和瀏覽器語音辨識搶麥克風），改用語音辨識的 `onsoundstart／onsoundend`：有聲音時隨機跳動、沒聲音時趴平；量音量失敗（沒權限等）也自動改用這種擬真音波。結束聆聽時一定關掉麥克風與 AudioContext。
- **至尊模式一律不用上拉選單＋模式頁整頁顯示（業主 2026-11-24 第四次）**：

  - 底部「至尊」鍵（`modeKey: "page"`）進入整頁的**模式頁 `/mode`**（`app/mode.tsx`→`features/elder/mode-page.tsx`，超派模式進這個網址會回首頁），在模式頁時模式鍵亮黃色膠囊。由上到下：會員抬頭（`MemberHeader stacked`：頭像＋姓名一列、獎銜標籤＋獎章圖一列）→「完善會員資料」→ 字體大小卡（`FontSizeCard`，按「套用這個字體大小」才套用）→ 訂單紀錄、帳號 → 換回超派模式（先確認，確認也是整頁）。原本的模式面板 `ElderSheet` 已刪除，動作在 `features/elder/mode-actions.tsx`。

- **至尊模式搜尋與超派模式同一套找法（業主 2026-11-24 回報：語音說「線上白金」找不到「安麗與白金線上溝通會」，超派模式卻找得到）**：`features/elder/elder-search.tsx` 原本只有完全比對＋模糊比對，沒有接 AI 語意搜尋。現在順序＝完全比對 → 模糊比對＋字元比對（`charsCourses`：查詢的每個字不分順序都在課程文字裡，至少 3 個字，不用 AI）→ AI 語意搜尋（`useSemantic`，完全比對沒結果才送出）；三者合併顯示，等 AI 時顯示「正在找相近的課程…」。**之後改超派模式（`courses-view.tsx`）的找法，至尊模式也要同步。**
