# 業主規則：共用介面元件（面板、提醒、動畫、按鈕、返回列…）

> 從 CLAUDE.md 原文搬來，內容一字未改（2026-11-22 瘦身）。動到這個領域的功能前請先讀；規則依時間順序，後面的條目常會「取代」前面的。

- **分享**：一律呼叫手機的系統分享選單（網頁用 Web Share、App 用系統 Share）；分享圖示**永遠使用各平台系統預設圖案**——iOS＝方框加向上箭頭、Android＝三個圓點相連。一律使用 `ShareIcon`（`src/ui/share-icon.tsx`）與 `shareLink`（`src/lib/share.ts`），不要自己畫別的。
- **上拉選單右上角的「進入完整內容」按鈕一律用 `SheetAction`（業主 2026-11-16 永久指示）**：深綠膠囊、白色粗體字（`src/ui/sheet-action.tsx`；例如系列選單的「顯示全部」、課程章節選單的「完整介紹」），不要再用純文字連結或各自畫樣式。這類選單同時要傳 `BottomSheet` 的 `onExpand`（與按鈕同一個動作）：按住面板任何位置往上拉，面板跟著手指長高，拉過一半距離放開或一路拉到最高處就直接進入內頁，沒拉夠彈回；`expandLabel` 是上拉時的提示文字。
- **上方返回工具列一律用 `TopBar`（業主 2026-11-15 永久指示：全站一致）**：返回鍵＋標題＋右側按鈕只有一個來源 `src/ui/top-bar.tsx`。全站頁面堆疊（`app/_layout.tsx` 的 Stack `header`）自動套用，頁面用 `PageHeader`（`features/page-header.tsx`）設定標題與右側按鈕；頁面內的狀態頁（例如中心專屬頁）放進 `Screen` 的 `topBar`。右側按鈕（編輯、分享…）一律用 `TopBarButton`，下緣陰影在 `TopBarShadow`／`TopBar` 內。不要再自己畫標題列或另做一套樣式。
- **全螢幕文字提醒一律用 `showFlash`（業主 2026-11-16 永久指示）**：模組在 `src/ui/flash-notice.tsx`（畫面上方大卡片：圖示＋標題＋說明，淡入停留淡出，固定寬高 190×184（業主 2026-11-16 高度縮成 80%、寬度不變，圖示與文字同步縮成 80%，圖示尺寸用 `FLASH_ICON`）、文字依字數自動縮小換行、位置靠上、點一下立即關閉；**出現時整個頁面背景暗化＋輕微模糊**（用 `ui/dim-backdrop.tsx`，跟卡片一起淡入淡出，不擋住下面的操作；業主 2026-11-17））。切換顯示模式、點小樹苗、點成就圖示……所有這類提醒都呼叫它，要改格式只改這一個檔案，不可另做。
- **小範圍讀取動畫「小瓢蟲」`LoadingLadybug`（業主 2026-11-17 定稿）**：`src/ui/loading-ladybug.web.tsx`（紅殼開闔、透明翅膀拍動、原地飛舞）。整頁／整個區塊在等資料用 `LoadingSapling`（`LoadingView`）；**只有一小塊在等**用小瓢蟲：按鈕送出中（`Button loading`、個人資料表單的儲存鈕）、**播放器的播放鈕等待播放時**（`PlayerControls`、`AudioBar`；課程頁按播放後取播放授權的空檔，舞台大鈕與待機控制列也換成瓢蟲）、通知設定的推播狀態、後台清單搜尋／載入更多、課程章節選單、全部課程搜尋。YouTube 的「讀取中」從載入、按播放、緩衝（state 3）到開始播放；LINE 等不准程式代按播放的環境，8 秒後自動不再顯示（見 `engine.web.ts` 的 `ytStopLoadingLater`）。iOS／Android 暫用系統轉圈圈。新增任何小區塊讀取都用它，要改動畫只改這個檔案。
- **流光漸層邊框模組 `GradientFrame`（業主 2026-11-17 永久指示）**：迷你播放器那圈網站色系（深綠、橄欖、金）高級反光漸層邊框（邊框粗 4.5px、135 度漸層、7 秒一輪的流動動畫、外圍陰影），**全螢幕文字提醒（`showFlash`）與迷你播放器共用同一組定義**，集中在 `src/ui/gradient-frame.web.tsx`（`FRAME_GRADIENT`、`FRAME_PAD`、`FRAME_SHADOW`、`FRAME_ANIMATION`、`frameBoxStyle()`、`GradientFrame` 元件）。要改粗細、顏色、動畫、陰影只改這個檔案，所有用到的地方一起變；以後任何要用這種邊框的地方都用它，不可另寫。iOS／Android 版暫用單色邊框（`gradient-frame.tsx`），App 上架前補。
- **背景暗化＋輕微模糊模組 `DimBackdrop`（業主 2026-11-17 永久指示）**：所有蓋在頁面上的彈出層共用同一組定義，集中在 `src/ui/dim-backdrop.tsx`：`DIM_ALPHA`（暗度，目前 0.6；曾試 0.75 嫌太暗，業主 2026-11-17 定 0.6）、`DIM_BLUR`（模糊，目前 3px，只有網頁版）、`dimStyle`、`DimBackdrop`。**已套用**：全螢幕文字提醒（`flash-notice`）、所有上拉面板（`BottomSheet`：確認、編輯、選單…）、照片放大（`EdmLightbox`）、個人資料視窗（`profile-prompt`）、新增教材選單背景（`add-material-fab`）。**已有彈出層開著時，全螢幕提醒不再多疊一層暗化**（彈出層元件呼叫 `useDimLayer()`，提醒用 `hasDimLayer()` 判斷），避免兩層疊成接近全黑；要調暗度或模糊只改這兩個數字；**新增任何彈出層背景都用它，不可自己寫 rgba 黑色**。iOS／Android 先只有暗化、沒有模糊（需原生模組，App 上架前補）。
- **緞帶顯示規則（業主 2026-11-17）**：緞帶文字、顏色、開關全部來自「設定 > 課程排序與條件」（`ribbonsFor`，`features/courses/ribbons.ts`），程式內不可寫死緞帶文字。**公開免費（`isPublic`）的課程，不論有沒有登入都顯示 `public_free` 緞帶**（原本登入後被省略，改名「限時免費」時才發現）。
- **載入速度守則（業主 2026-11-17 回報全部課程變慢，已優化）**：① **不可再引入大型圖示字型**（`MaterialCommunityIcons` 一個字型 1.3MB，只因底部選單一個圖示，所有人開網站都多下載；寰宇大學建築圖示改用 `ui/university-icon.tsx` 的 SVG）；新增圖示優先用 Ionicons 或自繪 SVG，建置後看 `embedded N files, X KiB` 有沒有暴增。② **資料讀取不等登入檢查**：`useApi`（`state/session.tsx`）一掛載就抓資料（請求本來就帶憑證），不再等 `/me` 回來；開啟網站時 `prefetchCommon`（`api/client.ts`）與登入檢查同時預先抓 `/courses`、`/center-art`、`/series-art`、`/centers`；`cachedGet` 提供記憶體快取（看過的頁面立刻顯示、背景更新）與同時請求去重，換帳號、登入登出時 `clearApiCache()`。新增任何會等資料的頁面照用 `useApi`，不要自己 `useEffect`＋`api()`（會沒有快取）。③ 後端 `listCourses`、`/me` 的資料庫查詢盡量用 `Promise.all` 同時送出（Worker 到 D1 每次來回約 70ms，一個一個查會累加）；新增查詢先想能不能併進現有的 `Promise.all`。
- **按鈕顏色與位置統一（業主 2026-11-19 永久指示）**：任何一列「取消／儲存」的按鈕：**儲存、確定（主要動作）一律在右邊、深綠實心**（`Button` 預設）；**取消、關閉、放棄一律在左邊、紅色外框＋紅字＋不填色**（`Button variant="cancel"`）。確認面板（`confirmSheet`）：一般確認＝左紅框取消＋右深綠確定；危險確認（刪除、移除、放棄）＝左灰框＋右實心紅底白字（`dangerSolid`）。不可再用 `secondary`／`ghost` 做取消鈕，也不可把儲存放左邊。
- **上拉選單的點選列＝共用元件 `SheetRow`（業主 2026-11-18 永久指示：所有上拉選單統一）**：`ui/sheet-row.tsx`（`SheetRow`、`SheetThumb`、`CountPill`）：縮圖→標題（最多 2 行，可加副標題）→右邊依序是「數量膠囊（`count`，**只顯示數字**，取代原本「有N個素材」）」、自訂標籤（`right`，例如梯次狀態）、**放大的向右箭頭（25 像素）**。已套用：清單區塊選單（`BlockSheet`）、系列／梯次選單（`SeriesSheet`）、關鍵字「N 堂課程使用」選單、移動教材到區塊選單。**新增任何上拉選單的點選列一律用它，不可再自己畫「›」或數量文字**；要改列高、箭頭大小、膠囊樣式只改這個檔案。分類選單（色塊格狀）與勾選列（專區移動）是另一種呈現，不在此列。這條取代前面「素材的上拉選單列表」「區塊選單」裡寫的「有N個素材」標籤。
- **上拉選單「上拉進入完整內容」只有按住灰色膠囊才觸發（業主 2026-11-20，原本整個面板都能拉太容易誤觸）**：`BottomSheet` 的上拉手勢只掛在最上方的灰色膠囊（`handleHit`，整條寬、上下各 12px 好按，手指或滑鼠都可）；面板其他地方只負責下滑收起、清單照常捲動。所有用 `onExpand` 的選單一起生效。
- **一句話提示（`flashText`）不可把時間切成兩半（業主 2026-11-22 回報「從上次看到的 7｜00 繼續播放」看不懂）**：`flashText` 會在第一個標點把長句切成「標題＋說明」；半形冒號後面緊接數字（例如 7:00、1:02:03）不算分隔點（`flash-notice.tsx` 的正規式 `:(?!\d)`，不可改用 lookbehind，舊版 Safari 會直接當機）。續播提示改為標題「接續上次進度」、說明「從 7:00 繼續播放」。新增提示句子要含時間時，用這個格式。
- **所有上拉選單：下滑關閉只能按住最上方灰色膠囊拖曳（業主 2026-11-22，全網設定，取代「面板其他地方負責下滑收起」）**：`BottomSheet` 已移除背景與面板本體的拖曳手勢，只有 `handleHit`（灰色膠囊那一整條）有手勢——往下拖＝關閉、往上拖＝展開（有 `onExpand` 才有）；網頁版膠囊永遠 `touchAction: none`。面板內容照常捲動，點背景仍會關閉。已用 CDP 真實觸控事件驗證：在面板內容上拖曳 160px 面板不動，在膠囊上拖曳面板跟著動。新增上拉面板一律用 `BottomSheet`，不可再自己掛下滑手勢。
- **`Dropdown`（`profile-prompt.tsx`）窄欄選項面板（業主 2026-11-22 回報三欄表單的選項被切掉、蓋在欄位底下）**：傳 `pop` 時選項面板寬度＝min(240, 螢幕寬−32)，開啟時用 `measureInWindow` 算位置，以欄位為中心、夾在螢幕左右各 16 之內；包住下拉欄位的卡片（`amwayCard`）要有 `zIndex`（react-native-web 每個 View 都是獨立堆疊層，沒設會被上方的 Email 欄位蓋住）。
