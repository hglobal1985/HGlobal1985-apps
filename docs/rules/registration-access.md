# 業主規則：報名、誰能瀏覽、費用與權限

> 從 CLAUDE.md 原文搬來，內容一字未改（2026-11-22 瘦身）。動到這個領域的功能前請先讀；規則依時間順序，後面的條目常會「取代」前面的。

- **點閱次數（業主 2026-11-16，2026-11-17 改名「瀏覽」→「點閱」並放寬）**：中心頁、系列頁封面上的「N 點閱」，每進入一次就 +1，不分是否同一人、同一天，**訪客也算、重新整理也算**（`page_views`、`bumpView`、`POST /center-views`、`/series-views` 都不用登入）。**從課程連結直接進入課程頁也算**：課程頁每次載入呼叫 `POST /course-views`，算進該課程「主辦中心」與「所屬系列」封面的點閱（總部主辦沒有中心就只算系列）。之後新增任何點閱統計也照這個寬鬆規則；畫面上一律叫「點閱」。
- **誰可以瀏覽（業主 2026-11-17）**：課程編輯 >「報名資格條件」最上方「誰能瀏覽課程？」六選一（`courses.view_scope`，`contract.ts` 的 `ViewScope`）：所有人含訪客 `all`／所有會員 `members`／寰宇夥伴 `hglobal`／中心會員 `center`／私密連結（需登入）`link_login`／私密連結（訪客可）`link_guest`。**新課程（含清單）預設 `all`（所有人含訪客，業主 2026-11-17 更正）。**（業主 2026-11-17 規則 B）「所有人含訪客」只代表任何人都看得到介紹，獎銜限制照樣保留可設定：沒有獎銜的人（含訪客）看得到、不能報名、也看不到章節內容；原本「鎖住並清成不限」的規則（`forceNoRankForAll`）已刪除。`is_public`（完全公開）必須同時沒有獎銜限制。）**不在範圍內的人：清單與搜尋看不到、課程頁 404（訪客 401）、不能報名；管理者與已報名／學習過的人照常看得到。**私密連結＝不顯示在前台任何清單、搜尋、首頁推薦、系列頁（後端與前端都擋），只有拿到網址的人能開**（開過的人只在自己的「學習中」）。沒有「對訪客隱藏」（已刪，`hide_guests` 欄位閒置）。`is_public` 由設定推算＝（`all` 或 `link_guest`）且免費且費用已公布，前端不要直接送 `isPublic`。判斷一律用 api.ts 的 `scopeAllows`／`isPrivate`。「最低獎銜」預設收起；「其他」子標題放「會長不受獎銜限制也可報名」，新課程預設打勾。
- **「已報名者照常」只適用付費課程（業主 2026-11-18 擴大）**：免費課程的報名與「學習過」都是第一次打開自動完成的，不算資格；之後課程改嚴（加獎銜限制、或「誰能瀏覽」縮小），不符合的人一律照現在的規則（章節鎖住／課程看不到、清單不出現、不能播放）。付費課程已繳費報名、審核中的人照常保留。判斷在 api.ts 的 `keepsAccess`（瀏覽範圍）、`freeRankBlocked`（播放與獎銜）。免費改成付費時，先前免費報名者仍保留（視為既得權益，業主未要求改）。
- **編輯模式預設收起（業主 2026-11-18，全站一致）**：課程／清單頁進入編輯模式時，「設定」（基本資料、報名資格條件、進階設定、上架與刪除）預設收起，標題叫「設定」，右側有「展開／收起」按鈕（`CollapseToggle`，`ui/collapse-toggle.tsx`，深綠膠囊）；清單的區塊卡（`BlockEditList`）也預設全部收起、同一時間只能展開一個（展開另一個會自動收起前一個），按鈕在區塊標題列最右側。之後新增任何「編輯模式裡的一長串設定／區塊」都用 `CollapseToggle`，預設收起。
- **鎖頭遮罩文字靠上對齊、教材區不再有標題（業主 2026-11-20）**：`styles.mask` 內容從上方開始排（不置中，因為教材可能很長）；課程頁檢視模式下「其他教材」四個字的標題刪除（一律統稱教材）；沒有章節、只有教材時不再顯示「敬請期待」，完全沒有內容才顯示「敬請期待／課程內容準備中」。
- **鎖頭遮罩模組 `LockMask`（業主 2026-11-21，全站唯一來源）**：`src/ui/lock-mask.tsx`＝半透明灰色色塊＋大鎖頭＋文字，**靠上對齊**；放在 `position: relative`、有最小高度的容器最後一個子元素，`lines` 一行一個文字，傳 `onPress` 整片可點。已用在：課程頁章節區與其他教材區（「報名後才能觀看」等）、**寰宇大學系列頁展開內容**（`SeriesCardPanel`：全部沒有權限時蓋一個，文字「按此開啟課程頁面／開通報名」，點整片進該課程頁）。新增任何「沒有權限」的內容區都用它，不可再自己寫遮罩樣式（取代前面「`styles.mask`」的寫法）。
