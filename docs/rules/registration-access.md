# 杜杜龍規則：報名、誰能瀏覽、費用與權限

> 從 CLAUDE.md 原文搬來，內容一字未改（2026-11-22 瘦身）。動到這個領域的功能前請先讀；規則依時間順序，後面的條目常會「取代」前面的。

- **點閱次數（杜杜龍 2026-11-16，2026-11-17 改名「瀏覽」→「點閱」並放寬）**：中心頁、系列頁封面上的「N 點閱」，每進入一次就 +1，不分是否同一人、同一天，**訪客也算、重新整理也算**（`page_views`、`bumpView`、`POST /center-views`、`/series-views` 都不用登入）。**從課程連結直接進入課程頁也算**：課程頁每次載入呼叫 `POST /course-views`，算進該課程「主辦中心」與「所屬系列」封面的點閱（總部主辦沒有中心就只算系列）。之後新增任何點閱統計也照這個寬鬆規則；畫面上一律叫「點閱」。
- **誰可以瀏覽（杜杜龍 2026-11-17）**：課程編輯 >「報名資格條件」最上方「誰能瀏覽課程？」六選一（`courses.view_scope`，`contract.ts` 的 `ViewScope`）：所有人含訪客 `all`／所有會員 `members`／寰宇夥伴 `hglobal`／中心會員 `center`／私密連結（需登入）`link_login`／私密連結（訪客可）`link_guest`。**新課程（含清單）預設 `all`（所有人含訪客，杜杜龍 2026-11-17 更正）。**（杜杜龍 2026-11-17 規則 B）「所有人含訪客」只代表任何人都看得到介紹，獎銜限制照樣保留可設定：沒有獎銜的人（含訪客）看得到、不能報名、也看不到章節內容；原本「鎖住並清成不限」的規則（`forceNoRankForAll`）已刪除。`is_public`（完全公開）必須同時沒有獎銜限制。）**不在範圍內的人：清單與搜尋看不到、課程頁 404（訪客 401）、不能報名；管理者與已報名／學習過的人照常看得到。**私密連結＝不顯示在前台任何清單、搜尋、首頁推薦、系列頁（後端與前端都擋），只有拿到網址的人能開**（開過的人只在自己的「學習中」）。沒有「對訪客隱藏」（已刪，`hide_guests` 欄位閒置）。`is_public` 由設定推算＝（`all` 或 `link_guest`）且免費且費用已公布，前端不要直接送 `isPublic`。判斷一律用 api.ts 的 `scopeAllows`／`isPrivate`。「最低獎銜」預設收起；「其他」子標題放「會長不受獎銜限制也可報名」，新課程預設打勾。
- **「已報名者照常」只適用付費課程（杜杜龍 2026-11-18 擴大）**：免費課程的報名與「學習過」都是第一次打開自動完成的，不算資格；之後課程改嚴（加獎銜限制、或「誰能瀏覽」縮小），不符合的人一律照現在的規則（章節鎖住／課程看不到、清單不出現、不能播放）。付費課程已繳費報名、審核中的人照常保留。判斷在 api.ts 的 `keepsAccess`（瀏覽範圍）、`freeRankBlocked`（播放與獎銜）。免費改成付費時，先前免費報名者仍保留（視為既得權益，杜杜龍未要求改）。
- **編輯模式預設收起（杜杜龍 2026-11-18，全站一致）**：課程／清單頁進入編輯模式時，「設定」（基本資料、報名資格條件、進階設定、上架與刪除）預設收起，標題叫「設定」，右側有「展開／收起」按鈕（`CollapseToggle`，`ui/collapse-toggle.tsx`，深綠膠囊）；清單的區塊卡（`BlockEditList`）也預設全部收起、同一時間只能展開一個（展開另一個會自動收起前一個），按鈕在區塊標題列最右側。之後新增任何「編輯模式裡的一長串設定／區塊」都用 `CollapseToggle`，預設收起。
- **鎖頭遮罩文字靠上對齊、教材區不再有標題（杜杜龍 2026-11-20）**：`styles.mask` 內容從上方開始排（不置中，因為教材可能很長）；課程頁檢視模式下「其他教材」四個字的標題刪除（一律統稱教材）；沒有章節、只有教材時不再顯示「敬請期待」，完全沒有內容才顯示「敬請期待／課程內容準備中」。
- **鎖頭遮罩模組 `LockMask`（杜杜龍 2026-11-21，全站唯一來源）**：`src/ui/lock-mask.tsx`＝半透明灰色色塊＋大鎖頭＋文字，**靠上對齊**；放在 `position: relative`、有最小高度的容器最後一個子元素，`lines` 一行一個文字，傳 `onPress` 整片可點。已用在：課程頁章節區與其他教材區（「報名後才能觀看」等）、**寰宇大學系列頁展開內容**（`SeriesCardPanel`：全部沒有權限時蓋一個，文字「按此開啟課程頁面／開通報名」，點整片進該課程頁）。新增任何「沒有權限」的內容區都用它，不可再自己寫遮罩樣式（取代前面「`styles.mask`」的寫法）。
- **課程類即使免費、完全公開也必須先報名才能收看；只有清單／教材類不用（杜杜龍 2026-11-22，取代「報名規則①」與前面「完全公開課程訪客／會員不必報名」的例外）**：後端 `canWatch`（訪客與會員兩處）與課程詳細的 `lockedAll` 對 `is_public` 的放行，都加上 `materialLike`（`MATERIAL_LIKE_SQL`）條件＝只有清單／教材類（`is_list`，或沒有章節的免費素材）完全公開時才免報名；一般課程（有章節）即使 `is_public`、免費，訪客只看得到介紹、章節鎖住（登入後按「免費報名」才開通），登入但沒報名的會員一樣鎖住（播放 403）。前端同步：`course/[id].tsx` 的 `noAccess` 與 `canRegister`（訪客也顯示報名鈕，按下先登入）、`courses-view.tsx` 的 `canWatch`。**管理員與有該課程編輯權的人仍可不報名預覽**（原本就有的設計，沒改）。測試 `public-dates`、`learning-started`、`resume`、`material-link` 改為先 `POST /orders` 報名再播放。
- **管理員與課程管理者也要先報名才能播放課程類（杜杜龍 2026-11-22，取代前面「管理員與有編輯權的人仍可不報名預覽」）**：`canWatch` 只有清單／教材類（`MATERIAL_LIKE_SQL`）才讓管理員、課程管理者直接通過；課程類一律看有沒有報名紀錄（沒報名＝403）。課程詳細的 `lockedAll` 對管理員也一樣（課程類沒報名＝章節鎖住），但**管理員仍拿得到教材連結網址**（`linkUrl`，編輯面板需要）。為了讓管理員能報名：`createOrders` 的獎銜檢查（`rank_required`）與 `freeRankBlocked`（獎銜、瀏覽範圍）對 `role === "admin"` 一律放行（仍要先按報名）。前端 `course/[id].tsx` 的 `noAccess`、`courses-view.tsx` 的 `canWatch` 同步。編輯課程內容不受影響（編輯用管理 API，不經 `canWatch`）。
- **成交百寶箱與關聯內容的鎖定一律以來源課程「報名資格條件」最新設定為準（杜杜龍 2026-11-24）**：成交百寶箱設「12% 以上（會長也可）、不用報名」＝它是純教材卡（`materialLike`），符合資格的登入會員直接瀏覽（`watchFree`），不符合的人（含訪客）整片蓋鎖頭遮罩（`LockMask`）。**連結區塊（品牌卡最前面的「成交百寶箱」）與區塊照片，鎖定狀態不看品牌卡自己，一律看來源課程**：`api.ts` 的 `lockStateOf`（與課程頁 `lockedAll` 同一條規則，含瀏覽範圍、獎銜、報名、完全公開），`courseDetail` 對每個來源課程算一次（`srcLock`）；來源的教材（`src`）`locked`／`linkUrl` 照來源判斷；連結區塊標題帶 `blockLocked`＋`lockLines`（遮罩文字：第一行「登入並符合獎銜才能使用／獎銜不符，目前無法使用」、第二行「限○○獎銜以上使用（會長也可）」），鎖住時 `photos` 一律空（只給 `photoCount`）；`GET /cover-media?kind=course&key=區塊編號` 對鎖住的人回空（`lockStateOfKey`）。管理者（有來源課程管理權）不受限。畫面：超派模式連結區塊展開內容蓋 `LockMask`（`lesson-list.tsx`）、相簿分頁該區塊展開蓋遮罩（`block-album.tsx`）；至尊模式用粗框大鎖頭 `ElderLock`（`elder-course.tsx`，不照抄超派）。課程頁教材區遮罩（`course/[id].tsx`）多一行不符合原因（`needRank`，清單／教材類寫「使用」、課程類寫「報名」，訪客也看得到門檻）。**之後任何會顯示成交百寶箱內容的新畫面（搜尋、首頁、系列頁…），都要先問來源課程鎖了沒。**
- **沒有權限也看得到全部預覽縮圖，上面蓋鎖頭遮罩（杜杜龍 2026-11-24，取代「鎖住時照片清單不給」）**：區塊照片 `photos` 一律照給（含鎖住的人），`GET /cover-media` 也不再擋；畫面上用共用的 `LockMask`（`ui/lock-mask.tsx`，**要放在容器最後一個子元素才蓋得住縮圖**）蓋在相簿分頁的照片格、區塊展開的教材清單上，文字＝`blockLocked`／`lockLines`（原因）；至尊模式用粗框大鎖頭＋淡化的縮圖。教材連結網址、`/search/scenes` 仍然對鎖住的人不給。
- **成交百寶箱頁面本身的鎖頭遮罩判斷（杜杜龍 2026-11-24 回報相簿沒出現遮罩）**：課程頁教材區要不要蓋 `LockMask`（`course/[id].tsx` 的 `materialsLocked`），原本只看「教材列是不是全部鎖住」；成交百寶箱的內容現在全是區塊照片、沒有教材列，所以沒蓋。改成：有教材列＝看教材列；**沒有教材列（只有區塊照片）＝看區塊標題是不是全部鎖住**。遮罩蓋住整個教材區（含清單、縮圖、相簿三個分頁）。
- **沒有權限的內容也要搜尋得到，並標示原因（杜杜龍 2026-11-25，取代前面場景搜尋「鎖住的課程不回結果」）**：①`GET /search/scenes` 不再略過鎖住的課程，每筆多 `locked`＋`lockLines`（原因，與 `lockStateOf` 同文字）；②`GET /search/semantic` 的其他項目（單一教材、區塊、課程介紹、EDM、相片）有 `courseId` 的，API 層用 `lockStateOfKey` 標上 `locked`＋`lockLines`，**鎖住的 EDM／相片不再給放大用的 `image` 圖址**；③單元列（`ChapterItem.locked`，超派 `ChapterList`、至尊 `ElderChapterRow`）、其他項目（`SemanticExtras`）、場景列（`SceneHits`）：縮圖中央蓋 `ui/thumb-lock.tsx` 的 `ThumbLock`（灰色半透明＋鎖頭，放在縮圖容器最後一個子元素），列上寫原因（`features/courses/lock-reason.ts` 的 `lockReason`：登入並符合獎銜／獎銜不符（限XX獎銜以上）／報名後才能使用）；④點擊鎖住的列一律 `flashText` 顯示原因；單元、教材、課程介紹仍會前往課程頁（可去報名），圖片與場景列只顯示原因、不放大不跳頁。**仍不列入搜尋的**：下架、「只限網址」的課程，以及「誰可以瀏覽」設定為會員／寰宇／中心限定且這位使用者不符合的課程（那是刻意的隱藏設定，若杜杜龍要連它們也搜得到要另外決定）。
