# 杜杜龍規則：共用元件（packages/ui，行動大學與繳作業系統共用）

- **共用元件資料夾（杜杜龍 2026-11-26 決定）**：寰宇行動大學（`apps/mobile`）與寰宇繳作業系統（`apps/check-app`）的畫面元件**只有一份**，放在 `packages/ui/src/`（資料夾結構與原本的 `src/` 一樣：`ui/`、`theme/`、`lib/`、`features/`）。改這裡的檔案＝兩個 App 一起變；**不可以複製一份到某個 App 裡另外改**。
- **找檔案的規則**：兩個 App 的 `@/` 路徑（`tsconfig.json` 的 `paths`）都是「先找 App 自己的 `src/`，找不到再找 `packages/ui/src/`」。所以程式照樣寫 `import { Button } from "@/ui/button"`，不用改。其他規則檔（`docs/rules/*.md`）提到的 `src/ui/…`、`src/theme/…`、`src/lib/…` 檔案，如果在 App 的 `src/` 找不到，就在 `packages/ui/src/` 同一個位置。
- **已搬進共用資料夾（第一批，2026-11-26，74 個檔案）**：設計規範 2.0（`theme/tokens.ts` 正本、`theme.ts`、`layout.ts`、`ui-scale.ts`）；介面元件（`Screen`、`TopBar`、`Button`、`Card`、`AppText`、`Field`、`Check`、`Chips`、`Select`、`Dropdown`、`DateSelect`、`Stepper`、`Slider`、`SegmentTabs`、`Section`、`FormBlock`、`NoticeBox`、`Pill`、`Fold`、`CollapseToggle`、`ListRow`、`IconButton`、`EmptyState`、`LoadingView`／`ErrorView`、`BottomSheet`／`SheetScroll`、`SheetAction`、`SheetRow`、`SettingsFooter`、`ShareIcon`、`DimBackdrop`、`GradientFrame`、`showFlash`／`flashText`、`LoadingSapling`、`LoadingLadybug`、`InAppBrowserBanner`、`InstallCard`、`ElderControls`、`Ticker`…）；`features/confirm.tsx`（`confirmSheet`）；全站行為（`lib/elder-mode.ts` 至尊／超派模式的切換與字體、`global-scale`、`no-page-zoom`、`stable-scrollbar`、`web-pull-refresh`、`bottom-gap`、`unsaved-guard`、`page-back`、`sheet-back`、`back-close`、`settings-page`、`in-app-browser`、`install-app`、`keep-scroll`、`fullscreen`、`search-memory`、`color-utils`、`error-report`、`inline-page`）。
- **每個 App 自己提供的「轉接檔」（共用元件會 import，兩個 App 在自己的 `src/` 各放一份，對外名稱要一樣）**：`@/lib/app-mode`（至尊／超派兩種模式各要顯示哪些功能：`useModeProfile()` 至少要有 `stackHeaders`、`sheets`）、`@/state/session`（`useSession()` 至少要有 `member`、`refreshMember`、`invalidate`）、`@/api/client`（至少要有 `UPGRADING_MSG`）、`@/features/player/shrink`（`reportPlayerScroll`）、`@/features/player/use-player`（`usePlayer()` 回傳 `{ track, playing }`）。**共用元件不可以 import 其他 App 專屬的檔案**；真的需要時，新增一個轉接檔並寫進這一條。
- **還留在行動大學、不共用的**：課程卡、課程封面、緞帶、品牌、縮圖標記、小樹苗、書櫃、食譜、廣播、寰宇大學圖示、底部主選單 `BottomBar`（含行動大學的分頁與重設行為）、`lib/share.ts`（用行動大學的分享預設值）、`lib/web-push.ts`、`lib/app-mode.tsx`（行動大學的模式設定檔）。
- **改共用元件時一定要兩個 App 都檢查**：`npm run typecheck -w @learn/mobile`、`npx tsc --noEmit -p apps/check-app/tsconfig.json`，兩個都過才能合併。至尊／超派同步檢查（`check-mode-parity.mjs`）與圖示精簡（`embed-static.mjs`）都已經把 `packages/ui/src` 算進去。
- **第二批（2026-11-27）已搬進共用資料夾**：
  - **底部主選單 `BottomBar`**（`ui/bottom-bar.tsx`，外觀、黃色膠囊、至尊／超派模式鍵與「偷看」動畫）：每個 App 只在自己的 `src/lib/nav-tabs.tsx` 提供 `NAV_TABS`（分頁清單，型別在 `ui/nav-types.ts`）、`useNavBadges`（紅點數字）、`useNavHidden`（依身分藏起來的分頁）、`useNavSkin`（特殊配色，例如行動大學的書櫃）、`useNavTrack`（記住分頁位置）、`onModeKey`（按模式鍵）、`MODE_PAGE`（模式頁網址或 null）。模式設定檔（`lib/app-mode.tsx`）要有 `tabs`、`bigNav`、`modeKey`。皇冠圖示 `features/elder/crown-icon.tsx` 也在共用資料夾。
  - **看圖程式 `EdmLightbox`**（`features/courses/lightbox.tsx`，從 `edm-viewer.tsx` 拆出來；兩指放大、拖曳、左右滑換張、檢視全部 `lightbox-grid.tsx`、下載、分享、上傳者、第幾張）。行動大學專屬的「相簿資料夾」「圖片資訊」由 `apps/mobile/src/features/courses/edm-viewer.tsx` 用 `registerLightboxParts` 接上（沒接的 App 就沒有那兩顆鈕）；行動大學原本 import `edm-viewer` 的寫法不用改（它會轉匯出）。
  - **相簿整套**：`features/courses/album*.tsx`、`lightbox-library.tsx`、`edm-info.tsx`、`features/uploads/album-upload(.web).tsx`、`album-replace(.web).ts`。它們目前仍呼叫行動大學的相簿 API，另一個 App 要用之前，要先在自己的伺服器提供同樣的相簿 API 與下面列的轉接檔。
  - **上傳與壓縮**：`features/uploads/video-compress(.web).ts`（瀏覽器內影片壓縮）、`upload-progress.tsx`（進度條）、`file-rules.ts`、`exif-meta.ts`、`hms.ts`、`features/admin/image-tools.ts`（照片壓縮 `cropCompress`）、`lib/album-memory.ts`；播放時間軸 `features/player/seek-bar.tsx`；上傳設定欄位 `features/uploads/upload-settings-fields.tsx`。
- **元件目錄 `@/ui` 分兩層**：共用元件的目錄在 `packages/ui/src/ui/index.ts`；行動大學的 `apps/mobile/src/ui/index.ts` 先匯出全部共用元件，再加上行動大學專屬的。共用元件裡寫 `import { … } from "@/ui"` 時，只能用共用目錄裡有的名稱（繳作業系統的型別檢查會擋）。
- **轉接檔完整清單（2026-11-27；共用元件 import、每個 App 在自己的 `src/` 提供）**：`@/lib/app-mode`、`@/lib/nav-tabs`、`@/state/session`（`useSession` 要有 `member`、`refreshMember`、`invalidate`；`useApi` 只有相簿用）、`@/api/client`（`api(method, path, body)`、`resolveUrl`、`UPGRADING_MSG`、`CoverMediaItem` 型別；相簿另用 `CourseSummary` 等）、`@/lib/share`（`shareImage`、`downloadImage`、`shareImages`、`downloadImages`）、`@/lib/thumb`（`useThumb`）、`@/lib/usage`（`trackUsage`）、`@/lib/feature-track`（`trackFeature`）、`@/lib/app-assets`（`APP_LOGO`、`APP_NAME`）、`@/features/player/shrink`、`@/features/player/use-player`；只有相簿套件才用的：`@/features/courses/edm-viewer`、`@/features/courses/use-search-settings`、`@/features/format`、`@/features/recipes/recipe-zone`、`@/lib/roles`、`@/state/ui-config`。
- **兩個 App 共用的上傳壓縮設定（杜杜龍 2026-11-26）**：正本在 Cloudflare KV「hg-shared-settings」（id `0287ee74946943298b5a7b7885930829`，兩個 Worker 都綁成 `SHARED`），程式在 `packages/server-shared/src/upload-settings.ts`（一般圖片／中心首頁圖／EDM 的長邊與畫質、影片高度／位元率／每秒格數、存檔格式）。行動大學：設定頁照舊（「儲存空間管理」），`saveConfig` 存檔時同步寫進 KV、`loadConfig` 讀取時以 KV 為準（第一次 KV 是空的就用行動大學目前的值當起點）。繳作業系統：「我的 › 上傳設定」（超級管理員，`GET/PUT /api/upload-settings`），作業照片與短影片壓縮都用這份。KV 跨地區同步約 1 分鐘。各 App 自己的大小與長度上限（行動大學短影音 60 秒、作業短影片 3 分鐘 80MB）不在共用設定裡。
- **第三批（2026-11-27）**：
  - **手機推播**：加密與傳送（RFC 8291、VAPID）抽到 `packages/server-shared/src/web-push.ts`（`sendPush(私鑰, 寄件網址, 裝置, 內容)`、`vapidPublicKey`、`encryptPayload`），行動大學 `apps/launch/src/push.ts` 只包一層接上自己的金鑰與網址（行為不變）；手機端的推播開關 `lib/web-push.ts`（`pushState`、`enablePush`、`disablePush`）在共用資料夾，兩個 App 的伺服器都要提供 `GET /push/key`、`POST /push/subscribe`、`POST /push/unsubscribe`。背景接收程式 `public/sw.js` 每個 App 各放一份（只差預設標題）。每個 Worker 各自的金鑰：Cloudflare Secret `VAPID_PRIVATE_JWK`。
  - **播放控制列外觀 `ControlsBar`**（`features/player/controls-bar.tsx`：播放／暫停〔讀取中＝小瓢蟲〕、時間軸 `seek-bar.tsx`、倒數剩餘時間、倍數、小視窗、全螢幕；時間與倍數文字在 `features/player/time-format.ts`）。行動大學課程頁的 `PlayerControls` 只把自己的播放引擎接到它身上；**要改播放控制列外觀只改 controls-bar.tsx，兩個 App 一起變**。
  - **影片檢視 `VideoViewer`**（網頁 `ui/video-viewer.web.tsx`、App `ui/video-viewer.tsx`〔expo-video〕：全黑全螢幕在畫面內播放、下方是 `ControlsBar`、✕ 與上一頁／返回鍵關閉）。
  - **「加入主畫面」卡片 `InstallCard`**：App 名稱改讀轉接檔 `@/lib/app-assets` 的 `APP_NAME`（行動大學＝寰宇行動大學、繳作業系統＝寰宇繳作業系統）。
- **還沒共用的**：行動大學的播放引擎本身（YouTube／Mux／音檔、迷你播放器、續播；`features/player/engine*`）、行動大學「儲存空間管理」頁本身（它還有其他行動大學專屬設定；上傳壓縮那幾欄改的是同一份）。
