# 業主規則：課程編輯、章節、教材、區塊、品牌、系列套用

> 從 CLAUDE.md 原文搬來，內容一字未改（2026-11-22 瘦身）。動到這個領域的功能前請先讀；規則依時間順序，後面的條目常會「取代」前面的。

- **上拉式選單一律下滑跟手收起（業主 2026-11-15 永久指示）**：所有從下方彈出的面板（確認、選項、編輯、分類篩選…）都用 `BottomSheet`（`src/ui/bottom-sheet.tsx`），手勢在這一個元件內建：往下滑時面板跟著手指移動，放開滑過一小段就順勢滑出並關閉，沒滑夠彈回；`swipeUpClose` 可再加「往上滑也算關閉」。新增任何上拉式選單一律用 `BottomSheet`，不要自己用 `Modal` 重做。
- **分享相關的文字與預覽格式一律放「設定 > 分享預設值」（業主 2026-11-16 永久指示，超級管理員編輯）**：資料在 `contract.ts` 的 `ShareSettings`（存在 UiConfig.share）。分享選單文字（一般邀請文字、單堂課程範本 `{主講人}`、`{職稱}`、`{課程名稱}`、章節範本 `chapterText`（課程有兩堂以上章節時，章節清單每列右側的分享鈕；`{主講人}`、`{職稱}`、`{章節名稱}` 一律取「章節」自己的設定，不用課程的）、其他教材範本 `materialText`、網址前引導文字）由 `lib/share.ts` 的 `shareLink`＋`shareMessage` 組出；LINE 預覽卡片（標題＝名稱＋分隔符號＋站名、備註＝📍地址換行學習金句）由後端 `og.ts` 組出（**預覽卡片不看「誰能瀏覽」**：任何已上架課程都照主辦中心格式出卡片，內容只有中心名稱、地址、金句與封面，不含課程名稱；2026-11-17 曾因為只讓「所有人」的課出卡片，造成所有會員課程在 LINE 退回預設樣式，已更正），單堂課程與章節的預覽卡片一律用「主辦中心」的標題與備註（總部主辦用 `hqName`）。新增任何分享相關文字，加進這一組設定與設定頁，不可寫死在別處。設定頁分成「① 一般分享 ② 課程的分享（單堂課程、章節）③ 清單（影片／檔案）的分享（素材清單 `listText`、清單裡單一影片 `listItemText`、外部連結 `materialText`）④ LINE 預覽卡片」；課程與清單類別的分享文字一律分開設定（業主 2026-11-16）。清單每段影片右側有分享鈕，網址＝清單網址?N。
- **課程編輯一律在課程介紹頁「原地編輯」（業主 2026-11-15）**：已刪除「設定→課程設定」頁，不可再做獨立的課程後台頁。編輯面板一律用 `EditSheet`（`src/features/course-edit/edit-sheet.tsx`），各區欄位在 `course-sections.tsx`、章節在 `lessons.tsx`。有人報名的課程不能永久刪除，只能「下架封存」；完全沒人報名才「刪除課程」。小編（各中心，只存行動大學）權限見 api.ts `rightsOf／courseCan`。
- **章節新增與編輯是同一個面板（業主 2026-11-16）**：`ChapterSheet`（`features/course-edit/lessons.tsx`，沒傳 lesson＝新增）。「主講」「總結」勾選同一列（勾總結＝章節名稱鎖住固定是「總結」，伺服器也強制）、分享者（打字建議本系統用過的名字）、章節名稱、獎銜職稱（中央詞庫建議）、日期（預設同課程日期，沒有「同上」）、影音上傳模組一次設定完；新增時先建立再依序送出影音／音檔，中途失敗可再按「新增」補完（不會重複建立）。Mux 與章節各自封面、逐字稿要章節建立後才能設定。不可另做第二套新增畫面。
- **其他教材（業主 2026-11-16 改版）**：只有「外部連結（旁邊有貼上鈕）、教材名稱（貼上連結後伺服器自動抓取網頁標題填入，可修改）、檔案類型（依連結判斷，顯示官方 Logo）」三個欄位；新增／編輯面板在 `features/course-edit/material-sheet.tsx`，不再有影音、音檔、附件上傳（影音上傳模組仍給章節與「完整版課程影片」用）。課程頁其他教材每一列：最左側是類型的官方 Logo（`BrandIcon`）、點一下開啟外部連結、最右側「分享」鈕（分享的是外部連結本身，文字範本在「設定 > 分享預設值」的 `materialText`）。「完整版課程影片」＝教材區塊最後一列（`lessons.is_full`，勾選新增、取消勾選移除，不能排序、不能複製），維持影音設定。
- **梯次排序（業主 2026-11-17 永久規則）**：同一系列的梯次一律「日期離今天越近的在上、越遠的在下」（用相差天數比，不分已過或未來；一樣近時未來的在前；沒日期放最後）。梯次選單、系列「顯示全部」頁、課程卡「還有 N 個梯次」都用 `nearestFirst`（`features/courses/sort.ts`），新增任何梯次清單也用它，不可另寫排序。（「全部課程」主清單仍依「課程排序與條件」設定。）
- **日期（業主 2026-11-16）**：全站日期一律用 `DateSelect`（`src/ui/date-select.tsx`），年份從 5 年後到 40 年前（`YEARS_BACK`）。「日」選單顯示星期：展開＝「23日（一）」、收起＝「23（一）」，週六、週日紅字（`SelectOption.danger`）。要改日期選擇的任何呈現，只改 `date-select.tsx`，全站同步，不可在別處另做日期選單。章節日期旁固定有「同課程」勾選，預設打勾（跟著課程日期）。
- **新增課程＝基本資料同一組欄位（業主 2026-11-17）**：「新增課程／新增清單」與編輯模式的「基本資料」共用 `BasicsFields`（`course-edit/course-sections.tsx`），新增畫面只多一個「主辦中心」選擇；要改欄位只改 `BasicsFields`。
- **課程專屬網址跟著主講人走（業主 2026-11-17）**：儲存課程時，主講人的英譯（`romanizeName`）和網址裡的名字不同，網址就重新產生（例：`la/lin-caijing-1` → `la/liu-yihui-1`）；英譯一樣（只是改錯字）不動。**舊網址存進 `course_url_aliases`（migration 0066）永遠有效**：短網址解析與分享預覽（`og.ts`）都認得，打開後網址列自動換成新的。換主辦中心也一樣（舊網址保留）。新編號會避開別名，不會讓舊連結跑到別的課。
- **網址列＝分享用規則網址（業主 2026-11-17）**：有專屬網址（`shortPath`）的課程，網頁版開啟後瀏覽器網址自動換成 `/中心縮寫/英譯主講人-1`（`app/course/[id].tsx` 的 replaceState），與分享選單給的網址一致；沒有專屬網址的才維持 `/course/編號`。新增任何可分享的頁面，也要讓網址列等於分享網址。
- **所有編輯面板的「儲存」與「取消／關閉」永遠同一列（業主 2026-11-17 永久指示）**：一律用 `EditSheet`，下方固定一列，左「取消」（沒有儲存就叫「關閉」）、右「儲存」；**不可**在面板內文裡另放儲存鈕。面板裡的內容自己有儲存動作（例如封面上傳）時，呼叫 `useSheetSave({label, onPress, busy, dirty})` 登記到下方那一列（`ArtUploader`、`EdmManager` 已照做）。章節面板編輯時按儲存會儲存並關閉；「播放檢查」這類輔助動作可以留在內文。
- **編輯動作要「瞬間」反應（業主 2026-11-17 永久指示）**：章節與教材的上下移動、複製、刪除，畫面一律先直接更新（`app/course/[id].tsx` 的 `optimistic()`：先改畫面、請求排隊在背景送、全部完成才重新載入、失敗就還原並提示），後端對應請求帶 `?lite=1` 只回 `{ok}`／`{id}`，不重建整份課程資料。新增任何排序、複製、刪除、勾選類的編輯動作，都用同樣做法，不可讓使用者等伺服器。
- **轉成素材（已移除，2026-11-21）**：只剩一種「教材卡」之後，「轉成素材／清單卡」的按鈕與後端 `convert-to-list` API 都已刪除；教材卡的行為由內容自動決定（見「只剩一種教材卡」）。
- **系列頁可直接新增素材／課程（業主 2026-11-18）**：系列頁（`SeriesPage`）右下角有「＋新增教材」（`AddMaterialFab`，只有超級管理員看得到，因為系列只有他能設定），新增面板的「系列」已預先選好目前這個系列（`NewCourseSheet` 的 `defaultSeries`）。
- **寬版搜尋框展開動畫（業主 2026-11-18）**：平板與手機橫放的搜尋框（`InlineSearch`）平常在列左邊，點進去動畫向右伸長、蓋住分類與模式按鈕；按 ✕ 或失去焦點且沒文字就縮回。
- **刪除的功能（業主 2026-11-18）**：① 課程編輯「進階設定」已刪除「指導單位」勾選、「不顯示在首頁推薦」勾選、「課程介紹」欄位（正式資料已把 13 門課的指導單位、5 門課的首頁隱藏全部清掉；小編建立課程也不再自動帶指導單位；首頁推薦不再看 `hideFromHome`）；② 「封面顏色」指定已刪除（基本資料、新增課程都沒有）：沒有 EDM／封面圖時，文字封面顏色由名稱自動隨機挑一款（同名稱固定同色，`ui/course-cover.tsx`），不可再做手動選色；③ **新增素材清單＝自動直接上架**（課程仍先是草稿；上架同時通知訂閱者）。資料庫的 `guidance_unit`、`hide_home`、`description`、`theme` 欄位保留但不再使用。
- **清單的「區塊」（業主 2026-11-18，取代「分類標題」；取消清單→清單頁→項目的多層）**：寰宇大學的素材小卡，點下去：系列只有一份清單且有區塊勾「顯示在上拉選單」→ 彈出 `BlockSheet`（`series-sheet.tsx`：封面＋區塊名稱＋灰色「有N個素材」，點一列進清單頁並自動捲到該區塊、展開它，網址 `?block=區塊編號`）；沒有任何區塊（或都沒勾）→ 直接進清單頁。區塊＝`lessons.kind='section'`，底下（到下一個區塊之前）的教材屬於它；欄位 `in_sheet`（預設勾選）、`brand_id`、`categories`（可複選）、封面沿用 `lessons.cover_key`（用 `LessonArt` 上傳；後端 `/admin/lessons/:id/art` 對區塊不要求「章節各自封面」）；區塊上拉選單封面優先順序＝上傳 > 品牌 logo > 預設圖。**清單頁的區塊預設全部收起**（`FullVersionList`），細橫條樣式不變。編輯模式（`BlockEditList`，`course-edit/lessons.tsx`）：每個區塊一張卡（標題列上下移動整塊、編輯、刪除＋底下教材＋「新增教材到這個區塊」，`NewMaterialSheet afterBlock`），「新增區塊」獨立放最下面（`SectionTitleSheet`＝區塊編輯面板：名稱、顯示在上拉選單、封面、品牌、分類）。`CourseSummary.blocks` 只列勾了顯示在選單的區塊（`loadBlocks`）。
- **區塊卡的展開狀態（業主 2026-11-18，款式 5）**：每張區塊卡右下角有「素材數＋▼／▲」膠囊（深綠底白字）；有一張展開時，其他卡變黑白＋淡化到 30%（全部收起時都是正常顏色）。
- **區塊的「移動教材」（業主 2026-11-18）**：編輯模式每個區塊卡的「新增教材」右邊有「移動教材」鈕，彈出 `PickMaterialsSheet`：列出本清單所有教材（依區塊分組）可多選勾選，已在該區塊的灰掉；按「移動」把勾選的教材（保持原先後順序）一起搬到該區塊最後面（`moveManyToBlock`，畫面先換、背景存檔）。單一教材另有每列的「移到…」鈕。
- **編輯面板共用欄位組（業主 2026-11-18）**：「品牌」「分類」這類每個編輯畫面都會用到的選擇，一律用 `features/course-edit/field-groups.tsx` 的 `BrandField`（品牌單選，標題列＋直接列出，**沒有展開／收起**）與 `CategoryField`（分類複選，`withInput` 可自己輸入），課程基本資料、新增課程／清單、區塊編輯共用；要改版面只改那個檔案，不可各自重畫。選項列 `Chips` 一律要有看得到的標題：傳 `title`（`label` 只給讀屏，不會顯示）。
- **編輯面板右上「素材／課程」二選一（業主 2026-11-18）**：`KindToggle`（`course-edit/kind-toggle.tsx`，用 `EditSheet` 的 `headRight`）放在「基本資料」與「新增」面板標題右邊，面板欄位跟著類型切換。新增面板可自由切換（專區預設值跟著換、自己改過的不動）；編輯既有課程：課程→素材要確認（不可逆，只有超級管理員、已有人報名擋下），素材不能轉回課程（提示「請另外新增一門課程」）。
- **連結區塊 `lessons.link_block_id`（migration 0084）**：品牌卡第一個區塊「新品特惠培訓直播」直接**連結**「安麗新品與特惠直播培訓」清單裡同品牌的區塊（沒有就自動在新品清單補一個空區塊），**內容只存一份**：`courseDetail` 把來源區塊底下的項目接在連結區塊後面（項目帶 `courseId`＝來源清單），`loadBlocks` 的數量與封面也取來源（封面＝來源清單的系列封面，改了自動一致）；項目的編輯、刪除、複製都用項目編號（`/admin/lessons/:id`）所以兩邊一致；`lessons/order` 對來源項目只在來源清單內換順序；播放用 `lessonOf`（會換成來源清單）；新增教材到連結區塊時前端（`NewMaterialSheet`）直接改加到來源清單的區塊。**不支援把項目搬進／搬出連結區塊**（會還原）。要再做別的「連結」同步，沿用這個機制。
- **安麗品牌專區訪客也看得到（業主 2026-11-18）**：專區標題一律顯示（就算還沒有卡片）；品牌卡是公開免費（`view_scope = 'all'`）所以訪客能點進去。品牌卡的連結來源清單優先用固定編號 `cxnfbadr`（`NEW_PRODUCT_LIST_ID`）找，因為清單名稱會被業主改（現在叫「安麗新品與特惠培訓」）。
- **專區標題列整條可點收合（業主 2026-11-18）**：`ZoneBand` 整條是按鈕，點任意處都收合／展開；裡面的「移動」「收合」鈕仍各自運作。
- **連結類型規則模組化（業主 2026-11-18）**：「貼網址自動判斷類型、圖示、預設名稱」的規則只在 `apps/launch/src/link-rules.ts`（`LINK_TYPES` 名稱與預設教材名稱、`LINK_RULES` 判斷規則由上往下第一個符合、`classifyUrl`、`itemIconType`），後端（`links.ts`）與 App（`features/link-types.ts` 的類型文字）共用；官方圖形在 `lib/brand-icons.ts`。要新增或調整類型只改這一組（步驟寫在檔案開頭）。**課程「其他教材」與清單類別頁的項目圖示共用同一套**：後端每個教材項目回傳 `iconType`（連結類型；清單裡貼的 YouTube 影片也是 `youtube`），畫面用 `BrandIcon` 顯示（`lesson-list.tsx`）。
