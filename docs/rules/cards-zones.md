# 杜杜龍規則：寰宇大學首頁、專區、系列、卡片與清單頁

> 從 CLAUDE.md 原文搬來，內容一字未改（2026-11-22 瘦身）。動到這個領域的功能前請先讀；規則依時間順序，後面的條目常會「取代」前面的。

- **課程資訊卡（杜杜龍永久指示，2026-11-14）**：「學習中」、系列「顯示全部」頁的課程資訊卡，**一律共用同一個元件** `CourseCard`（`src/features/courses/course-card.tsx`），格式完全一致，不可各自另做。格式：封面（16:9，文字封面只放大標題、不放分類／系列標籤）→ 資訊列：左邊只有三個標籤依序＝**主講人姓名、主辦（例：自強主辦）、價格**；已開通的課程**不顯示「已開通」**，價格位置改顯示亮黃色的「**已付費**」（不寫金額）或「**免費**」（與旁邊標籤同色）；審核中顯示「待審核」。**日期不是標籤，靠右同一列**；下方才是地點、學習進度條。杜杜龍日後要改任何一處的呈現，一律改這個元件，讓所有地方同步。「全部課程」頁的小卡片（`SeriesTile`）是另一種呈現（只有封面＋「瀏覽細節」）。
- **素材標示位置（杜杜龍 2026-11-17）**：素材小卡沒有虛線外框、沒有膠囊，只靠「素材專區」色帶分辨；黃色「📂 素材」膠囊放在上拉選單（`SeriesSheet`）標題的左邊。
- **主選單與設定的名稱圖示（杜杜龍 2026-11-17）**：主選單第二個分頁原「全部課程」改名「**寰宇大學**」，圖示改為建築物（`bottom-bar.tsx` 的 `BUILDING`，MaterialCommunityIcons `bank`）；設定頁的「我的圖書館」改名「**我的書櫃**」（圖示用書籍圖 `library-outline`），管理區的「圖書館管理」改「書櫃管理」；**全站已不再使用「圖書館」這個名稱，一律叫「書櫃」**（杜杜龍 2026-11-17；資料表與程式內部名稱 `library` 不變）。程式內部名稱與其他說明文字提到的「全部課程」就是現在的「寰宇大學」。
- **首頁一頁顯示與標題排版（杜杜龍 2026-11-18）**：首頁所有裝置、方向都必須一頁顯示、不可上下捲動（海報區 `stage` 是 flex 填滿剩餘高度，不可再給 `minHeight` 撐高）。橫式（寬>高，平板、手機、電腦一致）標題「寰宇行動大學」與會員資料並排成一行；直式維持兩行，大螢幕依寬度放大（`index.tsx` 的 `k`，上限 1.55，傳給 `BrandTitle`、`MemberHeader`、`HomeRail` 的 `scale`）。手機橫放（高<500）隱藏安裝提醒與備註（`compact`）。底部選單大螢幕：圖示 32、文字 15、列高 72，圖示放在固定方框內置中；底部安全區上限 20。
- **寰宇大學清單上方工具列寬版（杜杜龍 2026-11-18）**：平板（直橫式）與手機橫放（`useLayout().large`）：搜尋框一直展開直接輸入（`InlineSearch`）、分類框縮窄（112×`UI_SCALE`）、系列／單元／教育中心三顆各自獨立「圖示＋文字」按鈕且保持間距（`ViewToggle wide`）；手機直式維持原樣（收合放大鏡＋併成一組的三圖示）。
- **素材的上拉選單列表（杜杜龍 2026-11-18）**：寰宇大學點素材小卡彈出的 `SeriesSheet`，素材（`isList`）每列＝縮圖＋素材清單名稱＋右側灰色「有N個素材」標籤（`materialCount`，有影音來源或外部連結的項目數）；課程梯次列維持日期＋名稱＋狀態標籤。
- **寰宇大學右上角三個檢視按鈕的正式名稱（杜杜龍 2026-11-18 永久指示）**：**「所有系列」（原「系列」）／「單元」／「教育中心」**；名稱集中在 `features/courses/mode-flash.tsx` 的 `MODE_NAME`（切換提醒）與 `view-toggle.tsx`（無障礙名稱），文件、說明文字、提示一律用「所有系列」，不可再寫「系列模式／系列檢視」指這顆按鈕。
- **素材系列內可手動排序（杜杜龍 2026-11-18）**：系列頁（`SeriesPage`）詳細清單，若這個系列全部是素材清單，超級管理員每列右邊有上移／下移箭頭（手機不靠拖曳；先直接換畫面、背景存檔、失敗還原），`POST /admin/series-order`、`courses.series_order`（migration 0075）；素材系列的顯示順序（系列頁、寰宇大學上拉選單）一律用 `sort.ts` 的 `seriesOrdered`（手動順序，沒排過的維持原順序放後面）；課程系列維持「日期最近優先」`nearestFirst`。
- **「安麗新品與特惠直播培訓」（杜杜龍 2026-11-18）**：migration 0079 已把「新品上市培訓」9 份清單＋「安麗特惠直播」2 份清單合併成一份清單（原清單各變成一個區塊，教材原封搬入；舊網址不保留；系列封面沿用新品上市培訓的；點閱數相加）。之後若還要合併別的清單，同樣做法（依品牌／杜杜龍指定），不做自動依標籤合併。- **關鍵字管理與品牌頁小功能（杜杜龍 2026-11-18）**：關鍵字管理（`app/admin/keywords.tsx`）用「分類／系列／場地」分頁切換（不再排成一長頁）；「N 堂課程使用 ›」膠囊可點，彈出使用它的課程清單（點一列進課程）。品牌 Logo 頁（`app/admin/brand-logos.tsx`）每張 logo 卡有品牌標籤膠囊（名稱，編輯面板可改「品牌標籤名稱」）；「指定底色」自動建議 logo 最常用的 5 種顏色（`lib/logo-colors.ts`，網頁版 canvas 取樣）。
- **寰宇大學卡片自訂排序（杜杜龍 2026-11-18，方案 2）**：「所有系列」檢視最上方（只有超級管理員、沒搜尋時）有「排序卡片」列，按下進入排序模式：課程系列與素材專區各排各的，每張卡下方有 ◀ ▶ 與相鄰的卡交換（`SortableTile`，`courses-view.tsx`），畫面先換、背景存到 `UiConfig.seriesOrder`（同「設定 › 課程排序與條件」的順序，所有人看到一樣）；失敗還原並提示。
- **清單頁的返回鍵（杜杜龍 2026-11-18）**：素材清單頁（`isList`）按上方返回鍵，一律回到寰宇大學「所有系列」並定位到同一張卡（網址 `/courses?focus=s:系列名` 或 `c:課程編號`；`TopBar` 的 `backAlways`＋`backTo`，`CoursesView` 的 `focusKey` 捲到 `SeriesTile` 的 `nativeID=tile-…`），不會跑到主辦中心頁。一般課程維持原規則。
- **寰宇大學「所有系列」三個專區（杜杜龍 2026-11-18）**：**寰宇課程/活動/素材**（原「課程系列」）／**安麗官方素材專區**（原「素材專區」）／**安麗品牌專區**（新），順序固定，下面接「教育中心」。專區由 `courses.zone`（migration 0082，`contract.ts` 的 `Zone`／`ZONES`／`zoneOf`）決定，空字串＝依類型預設（課程→寰宇、清單→安麗素材）；**同系列的課程一起換專區**（後端 `updateCourse`、`/admin/zone-move` 都處理）。**專區只有超級管理員能改**：① 基本資料與新增面板的「專區」單選；② 每個專區標題列右邊的「移動」鈕（`ZoneMoveSheet`，`features/courses/zone-move-sheet.tsx`：列出其他專區的課程／清單，勾選後「移入」）。空的專區只有超級管理員看得到（為了能搬進去）。專區名稱只改 `ZONES`。卡片排序（◀ ▶）三個專區各排各的。
- **寰宇文化（杜杜龍 2026-11-18）**：原「認識寰宇」系列的 4 份清單（寰宇人才秀、王老師事業篇／生活篇、寰宇大會花絮回顧）已用 migration 0082 合併成一份清單「寰宇文化」（各自變區塊，放寰宇專區，系列封面與點閱數沿用）。
- **專區標題色帶有深色模式（杜杜龍 2026-11-18）**：寰宇大學各專區標題色帶（`courses-view.tsx` 的 `ZoneBand`）顏色集中在 `ZONE_PALETTE`：官方素材＝黃、品牌＝藍、教育中心＝紅，各有「淺色／深色」兩組（深色＝暗底＋亮字亮按鈕）；寰宇專區沿用站內主色。新增專區或改色只改這一張表；之後新增任何固定顏色的色帶、標籤，都要同時給深色版本。
- **卡片與系列架構改版（杜杜龍 2026-11-19，取代前面所有「素材」「系列檢視」「系列頁」的相關描述）**：
  ① **命名**：「素材」一律改稱「**清單**」；卡片只有四種說法：**中心卡、系列卡、清單卡、課程卡**（務必帶「卡」字）。清單裡面的內容仍叫「教材」。編輯面板右上角的切換是「清單卡／課程卡」。專區名稱＝「寰宇課程與活動」（杜杜龍 2026-11-20 由「寰宇課程/活動/清單」更名）「安麗官方清單專區」「安麗品牌專區」（三大專區**不可動**）。**程式內部與資料庫名稱（`is_list`、`material_*`、`amway_material` 等）暫不改**，等杜杜龍提醒再改。系列頁與清單卡頁的切換鈕叫「詳細列表／縮圖」（不再叫「詳細清單」，避免和清單卡混淆）。
  ② **第一層（寰宇大學「所有系列」）只有「系列卡」和「清單卡」**：沒有系列的**課程卡**一律放進「**未分類**」系列（`contract.ts` 的 `UNCATEGORIZED`；新增或清掉系列時後端自動設定；migration 0089 已把舊的 26 門搬進去），**只有超級管理員看得到**（`useSeriesSettings().listed`）；沒有系列的**清單卡**維持直接在第一層（品牌卡也是）。**系列裡只剩一張卡（被隱藏的不算）時，第一層直接顯示那張卡的內容、點了直接進去**；兩張以上才是系列卡，點了直接進系列頁（不再彈選單）。三個專區照舊，專區由卡片的 `zone` 決定。
  ③ **系列設定**（`series_settings` 表、`GET /series-settings`、`PUT /admin/series-settings`，超級管理員）：**標題只改顯示**（識別名稱 `courses.series` 不動，改名不會讓網址或歸屬壞掉；全站顯示系列名稱一律用 `useSeriesSettings().titleOf`）、「顯示在所有系列」開關（關掉只有超級管理員在第一層看得到，仍可用網址進入）。封面圖（直式 EDM＋橫式封面）沿用 `series_art` 與 `SeriesEdm`（封面上傳模組），**橫式用在第一層系列卡與系列頁上方大圖**。
  ④ **系列頁**（`series-page.tsx`）：內容自動收集（**不能手動新增教材或區塊**，已移除「＋新增教材」）；右上角「編輯」切換編輯模式（標題、顯示在所有系列、封面圖、每張卡 ◀ ▶ 排序與「隱藏」眼睛鈕，`POST /admin/series-order`、`/admin/series-hide`；隱藏只是不在系列頁顯示，仍可用網址、搜尋、單元找到，編輯模式淡化顯示）；**課程卡直式 3:4（一列至少 3 張）、清單卡橫式 4:3（一列至少 2 張），兩種都有就分兩區**（`SeriesCardTile`）；點卡片直接進該卡詳細頁，**右下角顯示教材數量（`materialCount`），0 的卡灰色淡化（`fadedStyle`）但仍可點**；右上角「詳細列表／縮圖」，詳細列表每列標題是**卡片名稱**（不用日期，日期放副標題）並顯示數量。排序規則 `seriesOrdered`：沒手動排過＝日期最近優先；排過之後新增的卡自動排最前面；課程卡與清單卡各排各的。
  ⑤ **清單卡頁**右上角同樣有「詳細列表／縮圖」（`FullVersionList` 的 `layout`）：縮圖＝區塊封面格（右下角教材數）、詳細列表＝全部教材一列一列（區塊名稱＋數量當分隔）。
  ⑥ **訂閱與點閱只放在「中心卡、系列卡、清單卡」的封面**（杜杜龍 2026-11-19：**課程卡不顯示**）；課程頁載入時仍照舊把點閱算進主辦中心與所屬系列。
- **首頁太擠時自動隱藏海報下方資訊（杜杜龍 2026-11-19）**：首頁左右兩個海報區（`HomeRail`）下方的資訊（主辦、日期、地點、金額／進度）在版面太擠時先自動隱藏；判斷在 `app/(tabs)/index.tsx`：用「顯示資訊時海報還剩多高」（已隱藏就扣掉 `HOME_INFO_SPACE`）與 `HOME_MIN_POSTER`（150）比較，加 12px 緩衝避免閃動，左右兩邊一起隱藏／恢復。使用者關掉上面的安裝提醒或公告、騰出空間後，會自動恢復顯示。圓點（切換張數）不隱藏；手機橫放（`compact`）維持原本壓縮方式不套用。
