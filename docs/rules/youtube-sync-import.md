# 杜杜龍規則：YouTube 同步、匯入工作、一次性匯入

> 從 CLAUDE.md 原文搬來，內容一字未改（2026-11-22 瘦身）。動到這個領域的功能前請先讀；規則依時間順序，後面的條目常會「取代」前面的。

- **教材日期自動讀連結日期（杜杜龍 2026-11-18）**：清單新增教材、課程「其他教材」貼上連結時，伺服器（`GET /admin/link-title`，`link-title.ts` 的 `fetchLinkInfo`／`extractDate`）除了標題也讀連結的發布日期（YouTube 影片頁的 datePublished／uploadDate；一般網頁的 article:published_time、JSON-LD datePublished 等），直接填進「日期」欄位顯示；日期欄空白或還是上次自動填的才會換，自己改過的不覆蓋；讀不到就維持空白。
- **YouTube 教材的影片長度與發布日期自動補齊（杜杜龍 2026-11-18）**：伺服器用 **YouTube 官方 Data API**（`src/youtube.ts`；需要 Cloudflare Secret `YOUTUBE_API_KEY`，杜杜龍在後台設定，不放 repo）：① 貼連結時 `/admin/link-title` 優先用 API 查發布日期（沒有金鑰才退回讀影片頁），填進教材「日期」欄；② 排程（每 10 分鐘，`backfillYoutube`，每次最多 50 個、1 次 API 呼叫＝1 單位額度，每天免費 1 萬單位）補全站所有 YouTube 教材（清單裡的影片來源與課程「其他教材」的 YouTube 連結）：**教材**日期空白就填發布日期（台灣日期）、**教材與章節**分鐘數是 0 就填長度；已有的日期不覆蓋；每個教材只查一次（`lessons.yt_checked_at`，migration 0080；連結換掉會清空重查）；沒設定金鑰就完全不動作。編輯模式的瀏覽器偵測（`useYoutubeLengthFix`）暫留當備案，但不再顯示提示文字。**不可用非官方的 YouTube 內部介面抓資料。**
- **匯入工作與上傳設定（杜杜龍 2026-11-18）**：`import_jobs` 表（migration 0081）＋排程 `processImportJobs`（`src/imports.ts`，每 10 分鐘最多 8 個，依 `seq` 順序）：把 YouTube 播放清單（官方 API playlistItems，影片標題與發布日期都帶入，已存在的影片不重複）、單支影片、連結（例如表揚專刊）、封面圖、照片檔匯入某份清單的某個區塊最後面；用 D1 直接新增工作列即可，不需要改程式。「安麗傑出創業者表揚大會」清單（`cdazqdd2`）的各年度區塊（2024～2012、更多鑽石表揚演講）就是這樣匯入的，樣式比照 2025／2026（區塊＋封面＋影片）。**上傳設定**在「設定 › 儲存空間管理」最上方：單檔大小上限（`fileMaxMb`，預設 30MB，1～95）、圖片壓縮長邊（`imageMaxSide`，預設 1024）、圖片畫質（`imageQuality`，預設 88），存在 app 設定；前端上傳模組與後端 `material-file` 都讀這組設定。
- **銅章會議：播放清單匯入成課程＋固定文字封面（杜杜龍 2026-11-19）**：① 匯入工作 `import_jobs`（kind `playlist`）的 `block_id` 填 `course:示範課程編號` 時，`imports.ts` 的 `runCoursePlaylist` 把 YouTube 播放清單每支影片建成一門課：設定（費用、獎銜、審核群組、誰能瀏覽…，除了 `NOT_COPIED` 那幾欄）全部照示範課程複製；名稱＝「銅章會議X年X月」（取影片上傳日，台灣時間）、活動日期＝上傳日、一個章節＝該影片（分鐘數由排程補）、已經在同系列的影片不重複；**主辦中心依影片標題判讀**（`guessCenter`：只用中央清單快照 `central_snapshots.centers`，標題沒寫或有歧義就留空不勾）；**先建成草稿**，確認 note 裡列的中心判讀沒問題再上架。示範課程＝`cq3gz76c`（銅章會議2026年10月）。② **固定格式文字封面**（`contract.ts` 的 `TEXT_COVER_PREFIXES`／`textCoverLines`）：名稱以「銅章會議」開頭的課程，封面一律只有文字＋咖啡色系底（`tokens.ts` 的 `coverBronze`）、固定「銅章會議（換行）X年X月」兩行（直式小卡一樣），後端 `courseArt` 不再用 YouTube 縮圖；手動上傳的 EDM／封面照舊優先。要新增別的固定格式封面只改那張表。
- **三項全站統一調整（杜杜龍 2026-11-20）**：① **固定格式文字封面（銅章會議）在直式／方形縮圖（寬高比 ≥ 0.9，例如縮圖檢視的卡片）顯示四行「銅章／會議／2026年／10月」**（`course-cover.tsx` 的 `splitFixed`），橫式大封面維持兩行；一般文字封面本來就依方框自動換行。② **數量膠囊 `CountPill`（`ui/sheet-row.tsx`）改成小圓形徽章**（28 高、垂直置中、不隨列高拉長），清單列表檢視與所有上拉選單一起生效。③ **訪客登入提示 `LoginPrompt` 只剩一顆按鈕，文字「尚未登入 免費註冊」，刪除旁邊的「解鎖更多功能與學習成就」小字**（取代前面 `LoginPrompt` 的說明）。
- **設定 › 同步 YouTube 清單（杜杜龍 2026-11-20，超級管理員）**：`app/admin/youtube-syncs.tsx`、資料表 `youtube_syncs`（migration 0094）、API `/admin/youtube-syncs`（GET 列表、POST 新增、DELETE、POST `/:id/sync` 立刻同步）、邏輯在 `imports.ts` 的 `runYoutubeSync`：貼 YouTube 播放清單網址（`playlistIdOf`），選「放進現有教材卡」或「新建一張教材卡」（新建＝獨立一張、沒系列、已上架、所有會員可看、免費、寰宇專區，之後到教材卡設定調整）；**手動按「同步」才匯入**（新設定的第一次由每 10 分鐘排程自動做一次 `processFirstSyncs`），只加還沒有的影片（用影片編號比對，不重複）、不開區塊、**最新的在最上面**（新影片依日期由新到舊，加在這份清單所有教材的最前面，`placeOnTop`）。「主持」判讀不出來就只省略「（主持xxx）」，影片照常匯入（杜杜龍 2026-11-20：不用人工檢查）。**名稱一樣的教材才加日期**：同一批裡或和這張卡原本的教材同名，就在後面加「（月/日）」，例如「2025年12月 王老師小線對焦會（12/15）」；不同名的不加（杜杜龍 2026-11-20）。**教材名稱格式 `syncTitle`**：「2026年11月 名稱（主持xxx）」——年月先看影片標題寫的「X年X月」，沒有就用影片日期；「主持」從標題的「主持／主持人」判讀，判讀不到就省略括號。需要 Cloudflare Secret `YOUTUBE_API_KEY`。「安麗與白金線上溝通會」杜杜龍要求暫時不要再同步（設定已建立但標示為已同步過，不會自動執行）。
- **新教材一律放最上面：最新的在最上面（杜杜龍 2026-11-20）**：教材的順序沒有全站自動依日期排的設定，全看手動順序（`lessons.position`）；為了讓「最新的在上」成為一致規則，**所有新增教材的入口都放在最前面**：貼連結（`POST /admin/courses/:id/materials`）、上傳檔案與雲端硬碟匯入（`createFileMaterial`）都用 `materialSlot`（放在這份清單第一個教材／區塊的位置，原本的往後挪一格；還沒有教材才放最後，完整版課程影片永遠最後）；在某個區塊裡新增，前端（`material-sheet.tsx`）搬到「區塊標題的正下方」；同步 YouTube 清單用 `placeOnTop`。**不包含**：杜杜龍之前手動排好的舊順序（不動）、匯入工作 `import_jobs`（歷史匯入，照來源清單順序放進指定區塊最後面）。
- **同步 YouTube 清單的「命名規則」（杜杜龍 2026-11-20）**：每份同步各自存一條規則（`youtube_syncs.title_format`，migration 0095），設定 › 同步 YouTube 清單的每張卡都顯示「命名規則」，可「修改命名規則」（`PATCH /admin/youtube-syncs/:id`）；新增同步時也可填（沒填＝`defaultSyncFormat`：「{年}年{月}月 名稱（主持{主持}）」）。可用代入欄位：`{年}`、`{月}`、`{日}`（標題寫的優先，沒有用影片日期；日期對不上標題的月份就省略日）、`{主持}`（判讀不到就連同所在的括號省略）、`{標題}`（影片原標題），邏輯在 `imports.ts` 的 `syncTitle`。改規則只影響之後匯入的；已匯入的按「依規則重新命名」（`POST /admin/youtube-syncs/:id/rename`、`renameYoutubeSync`，重新讀播放清單取標題與日期、只改名稱）。**王老師小線對焦會**的規則＝「{年}年{月}月{日}日 王老師小線對焦」（例：2026年3月14日 王老師小線對焦；播放清單 `PLRuUjdLupIVrvFjD3CbEOS-KV5I3Mh6kA`，同步設定 `yswang001`）；其他兩份（會長翡翠鑽石會議、安麗與白金線上溝通會）已補上原本使用的規則。新增任何會自動命名的匯入功能，都要照這個做法把規則存在設定裡、顯示在設定頁。
- **同步來的教材卡一律「日期最新的在最上面」（杜杜龍 2026-11-20 回報舊影片被放到整張卡最下面）**：每次同步（`runYoutubeSync` 的 `finish`）與「依規則重新命名」之後，都會呼叫 `imports.ts` 的 `sortMaterialsByDate`，把整張卡的教材依活動日期由新到舊重排（同一天維持原順序、沒日期放最後、章節在最前、完整版影片在最後）；**有區塊的卡是手動編排，不動**。原因：之前只保證「這一批新影片」彼此依日期排，若卡裡原本就有舊影片，新批次整批放最上面，會讓較舊的影片排到較新的後面。其他卡（美力之星、潮流創業等）是手動順序，不自動排。
- **命名規則已含 `{日}` 時不再自動加「（月/日）」尾巴（杜杜龍 2026-11-20 回報王老師教材標題多出「（5/4）」）**：`runYoutubeSync` 與 `renameYoutubeSync` 在規則包含 `{日}` 時，同名也維持規則產生的名稱（同一天有兩支影片就會同名）；規則沒有 `{日}`（例如預設的「{年}年{月}月 名稱」）才會對同名教材加「（月/日）」區分。標題一律只由命名規則決定，不可再另外加尾巴。
- **同步 YouTube 清單的「排序規則」與手動排序鎖定（杜杜龍 2026-11-20，修正前面「同步來的卡一律依日期新到舊」）**：每份同步各自選排序規則（`youtube_syncs.sort_mode`，migration 0096，設定頁「修改規則」或新增時選）：`date_desc`＝依日期新到舊（預設，每次同步與重新命名後整張重排，`sortMaterialsByDate`）／`top`＝新影片放最上面、其餘不動（`placeOnTop`）／`bottom`＝新影片放最後面、其餘不動（`placeAtEnd`）。**手動排序永遠第一優先**：使用者在課程頁手動調整這張卡的順序（`POST /admin/courses/:id/lessons/order`，上下移動、移動教材都走這個入口）時，該課程的所有同步自動 `sort_locked = 1`；鎖定後同步**只把新影片放進去（放最上面，選「放最後面」就放最後面），絕不重排既有順序**，也不會在重新命名時重排。設定頁每張卡顯示排序規則與鎖定狀態，「修改規則」可選規則、解除鎖定（恢復自動排序）。沒有同步設定的卡（例如美力之星）一直是純手動順序，不受影響。新增任何「自動排序」功能，都要先確認不會蓋掉使用者手動排好的順序。
- **同步時新影片一律「依日期」排，不是照加入時間（杜杜龍 2026-11-20，修正前面排序規則的鎖定行為）**：預設排序規則 `date_desc` 的意思是「日期最新的在最上面」，不論新舊影片。沒鎖定＝每次同步整張依日期重排；**已手動排序（鎖定）的卡＝既有教材順序完全不動，每支新影片依自己的日期插入正確位置**（`imports.ts` 的 `placeByDate`：插在第一個比它更舊的教材前面，找不到就放教材最後、完整版影片之前；有區塊的卡仍放最前面）。「新影片放最上面／最後面」是使用者明確選的規則，照選的放（鎖定時也照放）。這取代前面「鎖定後新影片一律放最上面」的寫法。
- **U40創業學院歷年課程一次性匯入（杜杜龍 2026-11-20；不納入「同步 YouTube 清單」，之後不再更新）**：`apps/launch/src/u40-import.ts`。匯入工作 `import_jobs`（kind `playlist`，`block_id` ＝ `pcourse:示範課程編號|開始日|結束日`，`url`＝播放清單編號，`title`＝課程名稱）：**一個播放清單＝一門課**（所有設定照示範課程「潮流創業」`cckaw2ew` 複製，只換標題與起訖日；沒有封面圖＝純文字封面；教材一律用「外部連結」存法〔不存成影片來源，才不會被 YouTube 縮圖當封面〕）；清單裡**每支影片＝一個區塊「第N堂」**，區塊裡一個教材＝這支影片的單支網址，名稱取自影片標題（拿掉日期、系列字樣、編號；沒有適當名稱就叫「第N堂」）、日期（標題日期，比上傳日還晚視為年份打錯改用上傳日）、主講人與獎銜（只有標題寫了才有；兩位以上只取第一位建檔，名稱保留全部；主持人不建檔）、長度（官方 API）。堂次：每支影片標題都有明確堂次就依堂次，否則依日期。解析規則 `parseVideoTitle`／`orderVideos` 有測試 `tests/u40-import.test.ts`。
- **課程頁也能匯入 YouTube 播放清單（杜杜龍 2026-11-23，選 B＋C）**：①**B**：編輯模式按「新增教材」跳出的面板最上方多一個「匯入 YouTube 播放清單」（`material-sheet.tsx` 的 `ytOpen`，排在「上傳檔案」之前，杜杜龍 2026-11-23 回報找不到而移到最上面），開 `YoutubeImportSheet`（`features/course-edit/youtube-import.tsx`）：貼網址、選填命名規則與排序規則，按「匯入」→ `POST /admin/youtube-syncs`（帶 `courseId`、`syncNow: true`）建立同步設定並**立刻匯入**，影片放這張卡最上面（不開區塊），完成後面板關閉。②**C**：課程設定（`SectionList`）多一列「YouTube 播放清單」（`SectionKey` 的 `youtube`，`YoutubeSyncSheet`）：列出這張卡自己的同步清單（`GET /admin/courses/:id/youtube-syncs`），可匯入新的、立刻「同步」、「修改規則」（命名＋排序）、刪除。③**權限**：同步設定的 sync／rename／PATCH／DELETE 與「帶 `courseId` 的新增」改成「超級管理員，或有該課程修改權限的人」（`requireSyncManager`、`requireCourseManager`）；**新建教材卡仍只有超級管理員**，「設定 › 同步 YouTube 清單」頁仍只有超級管理員能看，但課程頁建立的清單會一併顯示在那裡（同一張 `youtube_syncs` 表）。解除手動排序鎖定、「依規則重新命名已匯入的」只在設定頁。
- **刪除同步清單的兩種方式（杜杜龍 2026-11-23）**：課程頁「YouTube 播放清單」與設定頁的每份清單都有「只刪除清單」（原「刪除」，只刪同步設定、教材保留）與「刪除清單與關聯教材」（`POST /admin/youtube-syncs/:id/delete-with-materials`）。後者重新讀 YouTube 播放清單，把**這張卡裡** `media_type='youtube'`、`kind='material'` 且影片編號在清單內的教材全部刪除（連同附件／封面檔案，刪完重新編號），再刪同步設定，稽核 `youtube_sync.delete_with_materials`。教材沒記錄來自哪份同步，所以是以影片編號比對：手動貼的同一支影片也會一起刪。**讀不到播放清單或沒有 YouTube 金鑰就整個不動**（不會只刪一半）。確認面板有警告「無法復原」。
