# 業主規則：中心頁、訂閱、公告、課表

> 從 CLAUDE.md 原文搬來，內容一字未改（2026-11-22 瘦身）。動到這個領域的功能前請先讀；規則依時間順序，後面的條目常會「取代」前面的。

- **系列頁版面比照中心頁**：`SeriesPage`（`features/courses/series-page.tsx`）＝照片區＋清單／EDM 兩種檢視；照片區共用 `CenterHero`。
- **返回鍵的上一層（業主 2026-11-17）**：直接從分享網址進來（沒有上一頁）時，返回鍵依頁面的位置回到「上一層」：中心主辦的課程 → 該中心專屬頁；總部課程 → 全部課程；中心專屬頁（短網址或 `/courses?center=`）→ 所有中心清單（`/courses?view=centers`）。課程頁用 `PageHeader` 的 `backTo`（傳到 `TopBar`）；有上一頁時一律照常回上一頁。新增任何可被分享的頁面，都要給 `backTo`。
- **中心訂閱與廣播公告（業主 2026-11-17）**：中心頁封面左下角最左邊是**訂閱鈕**（`CenterHero` 的 `subscribe`：鈴鐺圖案與主選單「通知」一致、比膠卷標籤大兩倍、實心不透明、旁邊顯示訂閱人數；**全部中心都從 688 開始算**，`SUBSCRIBER_BASE`），膠卷標籤（門課／章節／點閱）維持原尺寸；**訂閱鈕高 44，鈴鐺下面有兩個小字「訂閱」（已訂閱＝「已訂閱」），已訂閱＝深綠底＋黃色實心鈴鐺、未訂閱＝白底＋綠色空心鈴鐺**；**所有中心的「點閱」顯示數都另加 688**（`CENTER_VIEW_BASE`，只加在中心，系列不加）；再按一下取消，訪客按會先去登入；**訂閱／取消的提示用全螢幕文字提醒 `showFlash`（鈴鐺圖示＋「已訂閱」＋說明），不用底部黑色小字 toast**；廣播公告新增／修改／刪除的提示也是。訂閱的人在「該中心有新課程／清單上架」（`notifyNewCourse`，私密連結、總部主辦不通知；業主 2026-11-17 起素材清單也通知；**上架的人自己一定也收到一則「已送出『新課程上架』通知（通知了 N 位訂閱者）」，不論有沒有訂閱者、是不是私密連結，用來確認通知有送出去**，上架者本人若也是訂閱者不會重複收到）與「中心管理員新增廣播公告」時收到通知（走 `notify()`，自動推播）。**廣播公告**（`center_broadcasts`）：中心頁地址下方的亮黃色橫條（網站標準亮黃色 `#FFD43B`，同「已付費」標籤；`CenterBroadcastBand`），強制一行、太長「…」＋「更多」，依設定秒數（預設 2 秒、`center_broadcast_cfg`）輪播，上下左右滑動切換，點一下彈出完整清單（日期＋內容，`BroadcastSheet`）；設定在中心頁 TopBar「編輯」面板最下面（`CenterBroadcastEditor`：新增多則、修改、刪除、每則停留秒數，按下就儲存），權限同中心封面編輯。**上拉面板的清單高度一律自動調整、寬度不變**：用 `SheetScroll`（`ui/bottom-sheet.tsx`，最高螢幕 62%），不要再寫固定 `maxHeight`。
- **中心「首頁圖」（業主 2026-11-17 命名）**：中心頁封面那張圖叫「**中心首頁圖**」，**不叫 EDM**（EDM 只指課程、系列的海報）；畫面文字一律寫「中心首頁圖」（`ArtUploader` 的 `noun` 參數：中心傳「首頁圖」）。中心頁封面**不放右上角放大鈕**，點封面任意處就放大看原始大圖，放大後與課程 EDM 共用同一個 `EdmLightbox`（下載、分享、拖曳、兩指放大縮小），不可另做。
- **中心頁 EDM 卡片（業主 2026-11-17）**：中心頁（`SeriesTile` 的 `flat`）一律直式 4:3（寬 3：高 4）、一列三張；EDM 比卡片窄長就寬度填滿、從預設位置開始；**EDM 太小／太矮（比 3:4 更橫）就完整顯示不裁切，背景用同一張圖放大模糊填滿**（`TopFill` 的 `fillBlur`）。
- **訂閱模組（業主 2026-11-17）**：中心首頁圖與系列首頁圖的訂閱鈕設計、尺寸、樣式一律統一，集中在 `features/courses/subscribe.tsx`：`SubscribeButton`（鈕本體）＋`useSubscribe(kind, name, loginNext)`（讀取、訂閱／取消、登入導向、全螢幕提醒）；`CenterHero` 的 `subscribe` 參數由它提供，中心頁與系列頁（`SeriesPage`）都用同一個。系列訂閱 API＝`/series-subscription`（沿用 `center_subscriptions` 表，鍵為 `series:系列名`），人數同樣從 688 開始；系列有新課程上架（`notifyNewCourse`）也通知系列訂閱者。要改訂閱鈕外觀只改這個檔案，不可在別處另畫。**系列內的課程或清單新增章節／教材時，也通知該系列的訂閱者**（`notifyNewContent`，業主 2026-11-17；已上架且非私密連結才通知訂閱者，同一門課同一類型 30 分鐘內只通知一次避免洗版；新增的人自己每次都收到「已送出『新章節／教材』通知」確認，含通知人數或「已合併」）。
- **中心清單隱藏「安麗公司」（業主 2026-11-17）**：「全部課程 › 中心」清單不列出「安麗公司」（`courses-view.tsx` 的 `HIDDEN_FROM_CENTER_LIST`），它仍在中央的中心清單裡，可以當課程的主辦單位／素材的建立單位；要隱藏其他單位就加進那個清單。
- **寰宇大學「系列」檢視最下面是「教育中心」區（業主 2026-11-18）**：順序＝課程系列 → 素材專區 → 教育中心（紅色系標題色帶 `ZoneBand red`，`#FCE1DE`／`#8F1D18`）；中心卡片沿用 `CenterTile`、排序同中心清單（`centerCounts`：課程數由多到少、「安麗公司」不顯示），點一下切到中心模式並進入該中心（`openCenter`）；搜尋時不顯示這一區。
- **寰宇大學預設永遠是「系列」檢視（業主 2026-11-18）**：「教育中心」模式不記憶（`courses-view.tsx` 只記住系列／單元兩種），每次進入都從「所有系列」檢視開始；從系列檢視最下面的教育中心區點進中心頁也不會改掉記憶。
- **表單區塊標題與素材標示（業主 2026-11-18）**：編輯面板裡「分類、品牌、系列、建立單位／主辦中心…」每一組都用 `FormBlock`（`ui/form-block.tsx`：淡綠標題列＋左邊深綠粗線＋框起來的內容），標題一定要有、要明顯區隔；素材（清單類別）的所有編輯面板，標題列右上角用 `EditSheet` 的 `material` 顯示黃色「📂 素材」標示（新增清單、基本資料、時間與地點、費用、資格、進階、上架、區塊、教材）。新增面板的欄位群組照做。沒指定系列的素材清單＝自己單獨一張卡，顯示在寰宇大學「素材專區」。
- **主辦單位可複選、共用元件；限時免費用日期選單（業主 2026-11-18）**：新增課程／清單的「主辦中心／建立單位」與進階設定的「主辦單位」一律用 `HostField`（`field-groups.tsx`：複選、顯示各單位已有課程數、**沒有展開／收起**；中心的人固定自己的中心）。「費用與審核」的限時免費開始／結束改用 `DateSelect`（開始＝當天 00:00 起，結束＝當天 23:59 止），不再手打日期時間。
- **圖片壓縮分兩類（業主 2026-11-18）**：設定 › 儲存空間管理 › 上傳設定：① **中心封面照片**（中心首頁圖，`centerMaxSide` 預設 2048、`centerQuality` 預設 95，`ArtUploader` 的 `center`；伺服器收圖上限 8MB）② **一般**（`imageMaxSide` 1024、`imageQuality` 88：課程／系列／區塊封面與上傳的圖片檔）。EDM 原圖固定 2048／0.9 不受影響。新增任何上傳圖片的地方要決定屬於哪一類。
- **寰宇大學專區標題列的「收合」（業主 2026-11-18）**：每個專區標題列（含教育中心）右邊、「移動」鈕的右邊有「收合／展開」鈕，預設展開；狀態記在本機 `hglobal:learn:zone-collapsed`（記住最後一次操作）。新增專區照用 `ZoneBand` 的 `folded`／`onFold`。
- **封面統計模組（業主 2026-11-18 永久指示：所有課程、教材清單、系列、中心的首頁封面圖一律同一組元件，改一次全網一起改）**：`features/courses/cover-stats.tsx` 的 `useCoverStats(kind, key, loginNext, noun?)`（進入頁面點閱 +1、讀取訂閱人數與狀態）＋`CoverBadges`（封面左下角：訂閱鈕＋「N 點閱」，**已刪除「N 門課」「N 章節」統計**）。用在三處封面：中心頁與系列頁（`CenterHero`，傳 `stats`）、課程與教材清單頁（`EdmStage`，傳 `stats`；播放影片時舞台換成播放器就不顯示）。**不可在頁面裡直接呼叫 `useSubscribe` 或 `/center-views`、`/series-views`、`/course-views`**，一律走這個模組；新增任何有封面的頁面也要用它。課程與清單的訂閱是這門課程／清單自己的訂閱（API `/course-subscription`，同一張 `center_subscriptions` 表、鍵 `course:課程編號`；顯示人數同樣從 688 開始，後端 `SUBSCRIBER_BASE`），有新章節或新教材時通知訂閱者（`notifyNewContent`：已經以系列訂閱者或已報名學員身分收過的不重複、30 分鐘內同類型只通知一次）；課程／清單自己的點閱存在 `page_views`（kind `course`，不加基數），刪除課程時訂閱與點閱一併清掉。此規則取代前面「中心訂閱與廣播公告」「訂閱模組」裡提到的膠卷標籤（門課／章節／點閱）。
- **所有封面的點閱數都加 688（業主 2026-11-18）**：中心、系列、課程、教材清單的封面，顯示的點閱數一律＝實際累計＋688（後端 `VIEW_BASE`，三個 `…-views` API 回傳時加上，只影響顯示、資料庫存的仍是真實次數）；訂閱人數同樣從 688 開始（`SUBSCRIBER_BASE`）。要改基數只改這兩個常數。這取代前面「點閱只加在中心，系列不加」的規則。
- **專區標題列右邊的數字＝內含教材總數（業主 2026-11-20）**：寰宇大學各專區與「教育中心」標題列的數字，統計的是底下所有層級的教材總數（把專區內每張卡、系列裡每一張課程／清單的 `materialCount` 全部加總），不是第一層的卡片張數；教育中心＝各中心旗下課程的教材總數（`centerCounts` 的 `materials`）。
- **所有「系列」一律先彈上拉選單，包含只有一張卡的系列（業主 2026-11-20；中心卡除外）**：寰宇大學第一層（`SeriesTile`）只要卡片有系列名稱（`hasSeries`），點了就先彈 `SeriesSheet`（右上「顯示全部」進系列頁），不論系列裡有幾張卡；沒有系列的卡才直接進去。封面顯示仍只有兩張以上才用系列封面（`inSeries`），單張系列沿用卡片自己的封面。這取代前面「系列裡只剩一張卡時點了直接進去」的說法。
- **第一層所有卡（中心卡除外）點了一律先彈上拉選單（業主 2026-11-20，取代「沒有系列的卡直接進去」）**：「王老師小線對焦會」這類沒有系列的獨立教材卡也一樣。`SeriesTile` 的 `open` 一律 `setSheet(true)`；選單內容：兩張以上的系列＝`SeriesSheet`；單張系列或獨立卡＝有區塊用 `BlockSheet`、沒區塊用 `MaterialsSheet`（列教材，教材也沒有就列章節 `ChapterList`）。
- **寰宇大學四個專區（含教育中心）預設全部收合，只在「這次開啟期間」記住（業主 2026-11-20，取代前面「預設展開、記住最後一次操作」存在裝置的做法）**：`courses-view.tsx` 的 `zoneOpenMemory`（模組記憶體變數，**不存 AsyncStorage**）：使用者展開／收合後，切換分頁回來狀態還在；重新整理網頁或重開 App 就忘記、回到全部收合。例外：① 搜尋、分類篩選、品牌篩選期間，專區一律展開顯示結果（`narrowing`，不改變記住的狀態）；② 從清單頁返回要定位到某張卡（`focusKey`）時，自動展開那張卡所在的專區。舊的 `hglobal:learn:zone-collapsed` 本機記憶已不再讀寫。
- **`/centers` 先回副本、背景更新（業主 2026-11-20 回報寰宇大學「教育中心」區塊每次比其他區塊晚約 2 秒）**：原因是 `GET /centers` 每次都要等會員中心（中央）回應。現在已有最近一次成功的副本（`central_snapshots.centers`）就**立刻回傳**，向中央確認最新清單與中心改名對應（`ensureCentersReconciled`）放到背景（`Ctx.defer`＝`waitUntil`，沒有執行環境如測試時就照舊等完成）；只有第一次沒有副本才等中央。新增任何「要等中央才能回應、但本地有副本」的清單，照這個做法（先回副本、背景更新）。
- **中心每月課表與中心頁版面（業主 2026-11-21，方案 A）**：① **課表**：每個中心每個月一張圖（`center_schedules`，migration 0100，`ym`＝YYYY-MM，同月重傳＝更換並刪舊檔；圖存 R2 `schedule/…`，`/media/pub` 認得它，儲存空間統計歸屬到該中心）。API：`GET /center-schedules?center=`（公開，新的月份在前）、`PUT／DELETE /admin/center-schedules?center=&ym=`（權限同中心首頁圖，`requireCenterArt`；上傳用 EDM 海報畫質 `shrinkImage(...,"edm")`，課表小字才清楚）。**新月份**上傳時通知該中心訂閱者（走 `notifySubscribers`／`notify()`，上傳的人自己收到「已送出『課表上架』通知」確認；更換同月不再通知）。畫面：中心頁課表卡 `ScheduleCard`（`features/courses/center-schedule.tsx`：**沒有標題**（業主 2026-11-21 刪除「本月課表」字樣）、縮圖、最近月份小鈕，**「歷年課表 ›」在月份小鈕同一列的最右邊**、彈出月份清單、點圖用 `EdmLightbox` 放大下載分享；本月沒有就顯示不晚於本月最新的；沒有任何課表整張卡不顯示）；上傳在中心頁「編輯」最下面的「課表管理」（`features/admin/center-schedule-editor.web.tsx`，選年月預設下個月、選圖、已上傳清單可刪；App 版只提示請用網頁版）。**暫時只收圖片，不收 PDF；公開給所有人（含訪客）。** 新增任何以中心為鍵的資料表，要加進 `center-reconcile.ts` 的 `KEY_COLS`（已加 `center_schedules`）。② **中心頁順序**：封面 → **廣播公告（緊貼封面正下方、左右滿版、沒有圖示，只有文字與「更多」，業主 2026-11-21 要求跟設計圖一模一樣；它是頁面第一個元素，用負邊距貼齊封面與螢幕左右，`center-broadcast.tsx`）** → 登入提示 → 地址 → 本月課表 → 課程／清單切換 → 卡片。③ **封面下緣一排**（`cover-stats.tsx` 的 `CoverBadges`，中心、系列、課程、清單封面共用）：**訂閱鈕在左下角、「N 點閱」在右下角**（兩端對齊，外層容器 `left:12,right:12`）。④ **課程｜清單切換**：中心頁兩種卡都有才出現切換（`courses-view.tsx` 的 `kindTab`，預設課程；只有一種就直接顯示那一種），卡片樣式照舊（直式 3:4、一列三張）。測試 `tests/center-schedules.test.ts`。
- **中心頁地址收進課表卡、刪除課表說明行（業主 2026-11-21，方案二）**：有課表時，地址放在課表卡最下面（`ScheduleCard` 的 `address`）：細線分隔、小字地址（單行「…」）、右邊「地圖 ›」與「歷年課表 ›」同字級同粗細，點整列開啟 Google 地圖；沒有課表才用原本的 `CenterAddress` 單獨顯示。課表圖下方「2026年11月・點圖放大…」那一排說明已整排刪除。地址資料仍只有登入會員讀得到（`GET /center-info` 需登入，訪客不顯示地址，維持原規則）。
